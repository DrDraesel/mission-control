### `edigeh/broll-mcp` 55★ MIT — public-domain b-roll for any MCP agent, **MCP handshake measured**
- `uvx --from git+https://github.com/edigeh/broll-mcp broll-mcp` → builds from `d8fda0a`, **39 packages installed in 1.06 s** (incl. opencv-python 45.7 MB); boot line: **`ffmpeg 9.0.2-essentials www.gyan.dev (https=True); scene detector backend: pyscenedetect-adaptive`**.
- JSON-RPC stdio probe from this box: **`initialize` OK** (protocol `2025-…`, server instructions returned) → **`tools/list` = 4 tools**:
  `search_footage` (brief → up to 5 ranked archive.org items with licence + collection tier), `inspect_item` (scene list with **real keyframe images** as MCP images, paged), `extract_clip` (re-encoded H.264 + faststart, ffprobe-verified ±0.1 s, 3 check frames), `get_provenance` (licence copied verbatim, commercial-use flag, ready-to-paste attribution).
- Engine design that matters for the faceless pipeline: **a provenance JSON is written before the clip**, each result reports `upstream_requests`, SQLite WAL cache makes repeats free, archive.org bot rules (1 req/s, 4 connections, Retry-After) respected. **No API key.**
- Not yet exercised against archive.org itself (search/extract calls were not run today) — the server, tools and our ffmpeg were.

### Remotion path in `digitalsamba/claude-code-video-toolkit` — **renderer works, the advertised hello-world does not**
- Sparse clone + `npm install` (Node 24) → **269 MB node_modules**, npm 11 **blocks postinstall scripts** (`npm warn allow-scripts … npm approve-scripts`), Remotion then downloads its **Chrome Headless Shell** on first render.
- Minimal composition (30 f, 640×360, plain AbsoluteFill): **renders here in ~4 s → 6,038 B H.264 MP4**, exit 0. The Remotion 4.0.544 stack is fine on this machine.
- The toolkit's `examples/hello-world` **`npm run render` dies at frame 0 with React error #130 (element type undefined)** — reproduced from a *full* checkout after the sparse one, so it is not a missing-file artefact. Bundling reaches 100%, composition is found, then every tab throws. **Quick start claim is currently broken on Windows/Node 24**; the value is the templates/skills/tools, not the demo.
- 82.8 MB repo, 620 commits, pushed yesterday. The toolkit's `docs/agent-video-jobs.md` exposes `video_job.py submit/status/result`, an MCP server and a `skills/video-toolkit/` skill explicitly listing **Hermes** — that is the integration surface to test next, not the example.
