## 2. Top finds (new to the ledger)

### 2.1 `fishfinger44/MatteDesk` — 38★, GPL-3.0 — **best find of the run**
Interactive **alpha / matte / roto desk** for VFX shots, 100% local, no cloud, no LLM needed.
- Windows 10/11 installer (one setup file, user-level `%LOCALAPPDATA%`, bundled Python, ends in a Start-menu shortcut), `MatteDesk-0.50-setup.exe` 126.5 MB verified.
- Pipelines **SAM 3.1** (say what to cut in English, or click/box/brush), **CoTracker3** (tracking), **MatAnyone2**, **VideoMaMa**, **BiRefNet_HR / ViTMatte** (edge engines), **Sapiens2** (body-part propose band), **LTX-2.5 Alpha-Gen** as stage 7.
- Outputs: alpha only (EXR/PNG), Nuke `.nk` + multichannel EXR, and **`outputs.json` data contract**; plus **Agent API + CLI** (the badge claim — verify the CLI surface before wiring it into the pipeline).
- Plates accepted as EXR / PNG / TIFF / DPX sequences or MP4/MOV; plate repair, deflicker, alignment, DepthCrafter depth.
- **Hardware:** 12 GB VRAM minimum, 24 GB recommended. ⚠️ **Stage 7 (LTX-2.5) wants 24 GB VRAM + 64 GB RAM** — on this 16 GB card the SAM3 / MatAnyone2 / BiRefNet / ViTMatte / CoTracker3 stages are the usable ones; LTX alpha-gen needs the 16 GB squeeze measured at 15.5 GB (see §4.1) or a paid cloud pass.
- ⚠️ LTX stage nodes need **ComfyUI core ≥ 0.39** → gated on the pending ComfyUI update. ViTMatte weights are **non-commercial (Adobe-trained)**; the commercial-clean edge engine is **BiRefNet_HR-matting (MIT)**.

### 2.2 `glumbis/effectcraft` — 29★, Apache-2.0 — EffectCraft + OpenFX + `.aep` import
Unofficial fork of `storytold/effectcraft` on branch `openfx`; its whole point is the two things the upstream does not do:
- **OpenFX plug-in hosting** via a separate helper (`ec-extension-ofx`) → RSMB / Twixtor / Sapphire-class OFX plug-ins.
- **File ▸ Import of After Effects projects** (`.aep` / `.aepx`).
- Windows x64 zip 68.1 MB verified. ⚠️ Built on EffectCraft **0.10.0** while upstream is **0.19.0** — 9 versions behind, last push 10-16, one maintainer. Treat as a **capability reference / migration bridge**, not a daily driver.

## 4. Video-generation fit for 16 GB VRAM (the important numbers)

### 4.1 LTX-2.5 VFX adapters measured on a 16 GB card (RTX 5060 Ti, 97 frames ≈ 4 s @24fps, distilled int8, 8 steps, cfg 1)
| Adapter | In → out | Wall time | Peak VRAM | Verdict |
|---|---|---|---|---|
| **Clean Plate** | 704×1280 → 704×1280 | 2.9 min | **15.5 GB** | ✅ keep — object removal for the matte stage |
| **Alpha Gen** | 720×1280 → matte | 3.1 min | **15.5 GB** | ✅ keep — this is the transparent-overlay path |
| Refine Details | 720×1280 → 1088×1920 | 11.2 min | 15.5 GB | ❌ drop, use FlashVSR+ |

Source: omnilabs.studio, measured 2026-10-28. The model does not fit in 16 GB, so part of it sits in shared system memory — the times include that. 97 frames is their ceiling (longer runs hung in VAE decode).

### 4.2 Licence reality (critical — this is a US machine)
- **LTX-2.x Community Licence**: free for entities **under $10M annual revenue**, **no territory restriction**, no mandatory branding; HF download is gated (login + accept terms). Official floor now stated as **16 GB VRAM**.
- **Kandinsky 6.0 Video: MIT**, no territory/revenue clause, 16 GB preset (distilled Pro + quantised text encoder, block offload), 44 kHz audio + lip-sync. **This is the cleanest MIT video+audio model that fits.**
- **MiniMax H3 and every derivative: US excluded.** `Pika-Labs/Pika-H3-Flex`, `D45Vinci`, `openjutsu`, `backlot`, `openfield` all inherit it. Do not spend install time.
- Wan 2.2 (Apache-2.0) remains the licence-simplest, but 5B tops out at 720p and generates no audio.

### 4.3 The AMD speed recipe is worth porting
`JoshyPorthos/ltx25-comfyui-amd-es` (1★, Spanish) documents a 16 GB RX 9070 XT run: 1080p 15 s went **57 min → 9 min** by (a) attention backend `comfy kitchen attention` (INT8 attention), (b) stage-2 sigmas `0.909375, 0.725, 0.421875, 0.0`, (c) stage-2 sampler `euler`, (d) temporal decode size **4096 with no blocks** (avoids the broken frame every ~2 s). The sigma/decode tricks are backend-agnostic → test on the RTX box after the ComfyUI update.

## 7. Integration plan (ranked, concrete)

1. **Install MatteDesk 0.50** (user-level Windows setup, 126.5 MB) and run it against one real clip: an IG-sized 1080×1350 still-plus-motion piece from `jasmiami-social`, or a RunTrack session stills sequence. Success criterion = a PNG/EXR alpha sequence plus `outputs.json` that an agent can read.
2. **Then pipe the alpha into the compositor**, not into `text-fx`: encode `yuva420p` (or use HyperFrames' transparent-video path / `open-3d-skills`' Safari-safe transparent video) — this is the concrete fix for the transparent-overlay limitation recorded on 10-19/10-20.
3. **Update ComfyUI to ≥0.43.0** — now blocking four things at once: official LTX-2.5 templates, Alpha-Gen nodes (≥0.39), Comfy-Pro-Alpha-Generator (≥0.38), and openjutsu/Kandinsky6 nodes. This has been the #1 action for 19 runs; MatteDesk just gave it a second reason.
4. **Test the AMD sigma/decode recipe** on the NVIDIA box after the update (stage-2 sigmas + `euler` + temporal 4096/no-blocks) — the cheap half of a 6× speedup if it transfers.
5. **Wire `motion-prompt` into the motion/video skill** as a name→prompt dictionary (192 named moves, 5 languages) so briefs stop saying "make it dynamic".
6. **Trial ReelMimic** on one reference IG reel — its per-shot critic loop is the same pattern as `achimala/dream-loop` (10-31 find) and is the reusable QC idea.
7. **Keep Kandinsky 6.0 as the MIT fallback** for any deliverable where the LTX community licence or gated download is a problem.
