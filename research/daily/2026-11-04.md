## Top finds

### 1. MeerCut — a real Windows NLE with a documented headless renderer (the missing Premiere export step)
- **CodeWithAmeer/MeerCut — 93★ GPL-3.0-or-later**, v1.0.0 (10-30), Windows 11 x64. Native C++, no telemetry, no account. `MeerCut-1.0.0-win64-portable.zip` **91.8 MB**, `…-setup.exe` 71.0 MB, **SHA256SUMS.txt** published (all verified).
- 54 title templates + full text inspector, 30 effects, 43 filter looks, 19 transitions, **.cube LUTs**, HSL/curves/wheels, SRT **and ASS/SSA import-export + burn-in**, motion tracking, stabilisation, Render Preview cache, **NVENC / QSV**, export MP4 H.264/HEVC, **MOV ProRes 422**, AV1, VP9, GIF, WAV/FLAC.
- Local AI (models downloaded on request, SHA-256 checked): **Robust Video Matting** background removal, **whisper.cpp** captions, **YuNet auto-reframe**, **RIFE 4.6** interpolation, **Real-ESRGAN** upscaling, scene detection.
- **The automation hook: `fa-render.exe`** — takes a `fa-project` **JSON** file, supports `--format`, `--hw nvenc|qsv|amf`, `--frames a:b`, `--size WxH`, `--fps`, `--crf`, `--subtitles file.srt|ass` (burn-in, repeatable), `--map file.csv` (per-frame source map), `--check` (validate only), `--backend cpu|gpu|auto`, and documented exit codes (0 ok / 1 usage / 2 project invalid / 3 render failed). `fa-probe.exe --encoders` reports which encoders actually work on the box.
- Limits stated in the README: no HDR and **no alpha-channel video export**, 10-bit writes 8-bit pixels, AMD AMF not built. GPL-3.0 → fine for internal/client work, copyleft if you ship the binary.
- Why it matters: this is the first free Windows NLE found in 6+ weeks of sweeps whose project format is a **plain JSON document** and whose renderer is **a CLI with exit codes** — i.e. it can replace the "assemble + export" step that currently forces a Premiere/AE round-trip, while staying fully local.
