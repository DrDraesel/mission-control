## 1. Verified on this machine

### `ed-asriyan/lottie-converter` 1,043★ MIT — the AE/Bodymovin → video bridge, MEASURED

Ledgered only today (found by the new `topic:lottie` probe), but it is a 2019-vintage C++ tool with a real Windows binary.
It is the **render** half of the Lottie lane that `libpag` (11-26) is the **runtime** half of.

- Release `v1.2.0` (2026-02-02) ships **`lottie-converter.windows.amd64.exe.zip` 329,770 B** — extract, no installer,
  no Python, no Node, no browser. VC++ runtime already present on this box (`ldd`: MSVCP140/VCRUNTIME140 all resolve).
- Binary set: `lottie_to_png.exe` + bash wrappers `lottie_to_{png,gif,apng,webp,webm}.sh` + `lottie_common.sh`.
  The PNG exe is the cross-platform one; the shell wrappers drive ffmpeg/gifski/img2webp for the other formats.
- **Measured here:**
  - `lottie_to_png.exe -o out_meteo -w 1080 -h 1080 package/fill/clear-day.json` →
    **361 frames at 1080×1080, RGBA (PNG colour type 6), 944 ms wall = 2.6 ms/frame (~382 fps), 12 MB of PNGs.**
  - Second input (`gatin.json`, lottie-web demo) → **195 frames at 400×400 in ~0.3 s**, same RGBA output.
  - `--output` is a **directory** for the PNG variant (not a filename) — the shell wrapper's `--output out.png`
    simply creates `out.png/` and fills it with `000.png…NNN.png`. Default = next to the source.
  - Frames visually confirmed: three sampled frames of the meteocons "clear-day" icon show a clean sun with rays
    **rotating between frames** on a transparent background.
- **Encoding the frame sequence (this box, ffmpeg 9.0.2):**
  - `-c:v libx264 -crf 20` → **59,853 B, 6.02 s @60 fps** (alpha flattened — good for delivery).
  - `-c:v prores_ks -profile:v 4444 -pix_fmt yuva444p10le` → **`yuva444p12le`, 82.3 MB, `alphaextract` succeeded**
    = a real alpha plane, the overlay/intermediate format.
  - **PITFALL: `-c:v libvpx-vp9 -pix_fmt yuva420p -auto-alt-ref 0` silently produced `yuv420p` with NO alpha** on
    this build — `alphaextract` dies `Requested planes not available`. Do not promise transparent WebM from this
    ffmpeg; use PNG frames or ProRes 4444 for alpha.
- When to use: any AE/Figma/LottieFiles motion asset (icon loops, logo stings, animated UI) dropped into a
  Remotion/HyperFrames-free pipeline. When not to: Lottie that the rlottie parser cannot express
  (the meteocons JSON rendered fine; metteocons is generated from SVG source, which is a decent compatibility signal).

### `basmilius/meteocons` 1,700★ MIT — 475+ animated icons, and the test input above

4 style variants (`fill`, `flat`, `line`, `monochrome`) as **animated SVG, static SVG and Lottie JSON**, shipped as
`@meteocons/{svg,svg-static,lottie}` (the Lottie package is `@meteocons/lottie@0.1.0`, **3.05 MB, one JSON per icon**).
That is a ready-made icon set for LabFlow/RunTrack dashboards *and* for social cards — and it doubles as a
compatibility corpus for the converter above.

## 3. Top finds (not on this box)

### `robbietilton/Editroom` 878★ MIT — the fastest-moving NLE of the week, and it is macOS-only

Created **2026-11-16**, **428 commits in 30 days**, pushed today. Native **Swift** editor for **macOS 14+ / Apple silicon**:
realtime 4K without proxies, grading, speed ramps, transitions, audio mixing with loudness-target exports, and
**natural-language cuts driven by Claude or ChatGPT over MCP against the currently open project** (plus an on-device
Apple Intelligence option). MIT app + bundled FFmpeg 9.1 (LGPL, separate-process rewrap) + Sparkle.
**Excluded here on platform only** — record it because it is the cleanest statement of the pattern this box's tools
(Editkin, CutVoke, Drift, kinocut) implement: *the agent talks to the open project, not to a render queue.*

### `sirioberati/ai-filmmaking-camera-control-seedance-2-5` 394★ MIT (code only) — the "pill pipeline"

137 filmmaking camera moves (dolly, crane, orbit, whip pan, FPV, one-takes, bullet-time, glambot, 360 booth) each as a
small **three.js** template. You render a grey 3D clip where every person is a **striped pill** (place, size, facing,
timing — no body to copy), send it with a prompt, and **Seedance 2.5 copies the camera move and invents the people**.
Node 22.12+ / ffmpeg / one Chrome download for Remotion. **The generation step is paid** (Tein-hosted Seedance 2.5,
own key; drafts 480p) and NOTICE.md excludes the 33 curves distilled from copyrighted films plus the faces/voices and
brand shots in the examples. **Adopt as vocabulary + previs engine, not as a free pipeline** — same role
`showheyohtaki/motion-prompt` (192 named moves) plays for prompts.
