**Correction to yesterday's note:** the `text-fx` overlay coming out `yuv420p` is **not** a libvpx build problem — the library deliberately strips alpha and relies on a **colorkey against black** when compositing. Practical consequence: never stack a `text-fx` output over footage with `overlay`; always use its compositor (or re-encode frames yourself to `yuva420p` if you truly need an alpha layer).

## 2. Video generation that fits 16 GB — LTX-2.5, now quantified

| Quant | Weights | Recommended GPU (per GGUF repo) |
|---|---|---|
| Q2_K | ~6.8 GB | 10–12 GB |
| **Q3_K_S** | **~7.8 GB** | **12–16 GB** |
| **Q4_K_M** | **~11.5 GB** | **16–20 GB** ← this box |
| Q5_K_M | ~14.2 GB | 20–24 GB |
| Q6_K | ~16.8 GB | 24 GB |
| Q8_0 | ~23.0 GB | 32 GB+ |

- **`agosh/LTX-2.5-Comfy-GGUF`** — live, **ungated**, 10,330 downloads, 7 quant files, last modified 08-16. **`Lightricks/LTX-2.5`** official repo is **`gated: auto`** (HF token + licence click) — 2.04 M downloads, 8,549 likes.
- The pipeline has four parts and **the Gemma 4 12B text encoder (26.3 GB bf16 / 15.4 GB int8) never sits in VRAM with the transformer** — encode the prompt, then offload. That is what makes 16 GB viable with a 15.7 GB transformer.
- Install path after the ComfyUI update: `ComfyUI-GGUF` → `Unet Loader (GGUF)` with a Q4_K_M file in `models/unet/`, keep the **INT8 text encoder**, launch `python main.py --lowvram` (add `--cpu-vae` if tight). Total download ≈**34 GB** for the Q4 route (saving is VRAM, not disk).
- Independent measurement remains the reference: LTX-2.5 int8 on a 4070 12 GB = **11.4 GB peak / 45 GB RAM / ~7 min per 5 s 736×1280 clip**. On a 16 GB card with Q4_K_M expect *better* fit, not necessarily faster.
- Licence: Lightricks **Community Licence** — free local use and sellable outputs for small teams; gated weights, resale of fine-tunes excluded.

1. **ComfyUI update — still the single blocking action.** Local **v0.25.0** vs upstream **0.39.x**. Nothing in the local-gen lane (LTX-2.5, H3, Kandinsky, EasyCache) can be evaluated until this is done. The 10-20 GGUF table above is the *post-update* plan; it changes nothing until then.
2. **Concat v0.2.8 is worth one real test** — it shipped today, has an agent JSON-RPC API, AGPL is fine for internal work, and it is the closest free CapCut/Premiere substitute with a Windows installer (82.6 MB). Test: take one 9:16 social cut end-to-end (import → local Whisper captions → export) and time it.
3. **Do not build an alpha-overlay path on `text-fx`.** Use it for burn-in only; if a true alpha layer is needed, render PNG frames and encode `yuva420p` explicitly.
4. **Read the 180-repo benchmark before choosing a render skill** (`zhuyansen/awesome-claude-video-skills` → `data/skills.json`). Prefer SAFE-graded skills: `iart-ai/motion-skills` (610★) and `motion-graphics-skills` (174★); treat `howseen-ai/claude-motion-design` as CAUTION.
5. **Carousel/asset lane:** the real answer remains `open-pencil` (headless CLI + MCP) — today's carousel query produced nothing competitive. Add `figma alternative` next run to keep the design lane covered.
