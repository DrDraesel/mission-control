## 2. Top finds

### 2.1 `webadderallorg/Recordly` — 34,864★ · AGPL-3.0 — the Screen Studio replacement, Windows included
Recordly records a screen (or one window) and turns it into a finished demo: **automatic zoom suggestions from cursor activity**, smooth cursor movement with motion blur/click bounce/sway/loop, **webcam bubble overlay** (presets, mirror, roundness, zoom-reactive scaling), styled frames (wallpapers, gradients, blur, padding, shadows), timeline trims/speed regions/annotations/extra audio, `.recordly` projects, **MP4 + GIF export**, and a community **extension marketplace with render hooks**.
- **Windows 10 Build 19041+** with a **native Windows Graphics Capture helper** (cursor hiding works) and **native WASAPI** audio; macOS 14+ uses ScreenCaptureKit; Linux falls back to Electron capture (no cursor hiding).
- Licence: badge says AGPL-3.0, API says NOASSERTION, `LICENSE.md` = **GNU AGPL-3.0** → fine for internal/own and client work, copyleft if you redistribute a modified binary.
- **Windows build verified:** release v1.4.0 → `Recordly-windows-x64.exe` **185.3 MB**, HEAD 200 (185,307,721 bytes).
- **Caveat that matters for automation:** it is a **GUI app with no CLI/headless API**. It cannot be driven from Python/ffmpeg. Its value is *manual* demo/product videos (RunTrack, NeuroSync, LabFlow walkthroughs) — not batch pipelines.
- Provenance: it is a **fork of OpenScreen** ("substantially modifies the OpenScreen foundation"); the fork has 7× the upstream's stars.

### 2.2 `getopenscreen/openscreen` — 4,812★ · **MIT** — the licence-safe half of the same family
Upstream of Recordly, MIT, actively maintained (**pushed today**, v2.1.2 10-19). Same core: record → auto-zoom → annotations → wallpaper/gradient frames → MP4/GIF, **GPU-accelerated, no watermark, no account**.
- **Windows verified:** `Openscreen.Setup.2.1.2-x64.exe` **178.9 MB** + arm64 157.2 MB (plus AppImage/deb/pacman/rpm, dmg/zip for mac).
- Pick **OpenScreen (MIT)** unless you specifically want Recordly's webcam bubble + extension marketplace; then take the AGPL and don't redistribute a modified build.

### 2.3 `wheresryan22/anatomy` — 19,475★ · MIT — best clinical-explainer generator found to date
A Claude/Codex/Antigravity/OpenCode **agent skill that explains an idea by building it as a working object** — then drawing it as a **crafted isometric figure** with dozens of small, solid, shaded parts.
- Three output kinds from one kit/camera/craft rules: **SVG** (four-tone shading, painted back-to-front, framed card with title + hint + live readout), **SVG+WebGL** (fire, exhaust, water, caustics, lamp light, steam — shader sits *inside* the isometric camera; the SVG still reads without WebGL), and **3D (beta)** (parts re-projected and re-shaded every frame).
- Ships as standalone HTML, a lone `.svg`, or **React/Next components**; includes `scripts/capture.mjs` / `drive.mjs`; **Node ≥20.10, zero npm dependencies, no API keys**.
- Install: `npx skills add wheresryan22/anatomy -g` (v1.1.0 → `anatomy.zip` 3.0 MB).
- **Why this one is different:** every number the figure shows comes from the same small model that moves its parts, and it audits itself by zooming into every joint. For clinic content — knee valgus, force-plate load paths, HRV/autonomic wiring, EEG electrode montage — this converts an explanation into an interactive, on-brand diagram instead of a stock illustration.

### 2.4 `Aseiel/VideoHighlighter` — 287★ · AGPL-3.0 — local OpusClip, Windows-native, no API key
Local desktop app: drop raw footage, it **scores strong moments from scene, motion, audio, objects, actions and the transcript**, shows *why* on a signal timeline and in a report, then exports a **highlight reel plus the individual clips**.
- **Nothing is uploaded**; the basic pipeline needs **no API key** (Ollama-powered local LLM, Whisper transcript, optional local translation, FFmpeg bundled).
- Windows/macOS/Linux; **Intel, AMD and NVIDIA** GPU backends (separate setup docs per vendor, plus remote-Ollama-on-LAN).
- Created 2025-09-19, pushed **10-22**, v0.14.1 → `00-VideoHighlighter-Windows-Setup.exe` **582.4 MB** verified.
- Use cases it names map onto ours: 4-hour VOD → highlight reel, GoPro/drone card → finished film, CCTV/trail-cam → minutes that moved. AGPL: fine locally.

### 2.5 `jd-opensource/JoyAI-Video-Edit` — 1,966★ · Apache-2.0 — streaming video editing model (watch only)
JD's **real-time open-ended video editing** model: autoregressive diffusion edits the frame as it plays — subject, local, background, style, motion, reference-guided — with **no length limit**. ~**30.19 FPS at 720×1280** end-to-end, **480p 24 FPS on a single RTX 5090**. Created 08-04, pushed 10-17, no GitHub releases.
- **Not a 16 GB route** (the published numbers are 32 GB-class 5090). Logged as the direction of travel: editing as a stream, not an export.

### 2.6 `KnifeLemon/Filee` — 10,726★ · MIT — the offline asset converter
**255 formats**, drag & drop, **no upload, no Office install**: images, PDF, Word, Excel, PowerPoint, HWP/HWPX, video, audio, e-books, archives. C#, Windows-native.
- v2.0.0 (10-21) → `Filee-2.0.0-win-Setup.exe` **128.4 MB** + `Filee-2.0.0-win-Portable.zip` 154.6 MB + SHA256SUMS.
- Pipeline role: the annoying step before every render — HEIC→PNG (phone photos for IG), webp/avif, docx→pdf, mov→mp4 — without touching a web converter that uploads patient or client material.

### 2.7 `alchaincyf/huashu-art-motion` — 4,969★ · MIT — style library for code-rendered explainers
**36 art styles** (cave painting, Egyptian mural, Van Gogh, Klimt, Bauhaus, 8-bit, vaporwave…) × **9 explainer grammars** (Kurzgesagt, Vox, whiteboard, storytime, kinetic type, 3Blue1Brown, keynote UI, finance charts) + 8 parametric clips. Each style ships a runnable Canvas scene, a renderer and a signature transition, driven by a JSON spec.
- `npx skills add alchaincyf/huashu-art-motion`; needs `uv` + ffmpeg + Playwright Chromium. Chinese-first docs, `README.en.md` exists. v1.2.0 10-16; already adopted into nexu-io/open-design's motion-design skill.
- Value here is **style recipes**, not the renderer — the code-rendered-skill lane is commoditised (a dozen ≤70★ clones a day), so only take repos that carry a real visual vocabulary like this one.

### 2.8 `nikopueringer/CorridorKey2.0` — 1,093★ — Corridor Digital's keyer, non-commercial licence
Green/blue-screen keying from the Corridor Crew, Python. **Licence: CC BY-NC-SA 4.0 + additional terms** — critically, **the images/video you produce are yours and may be used commercially**; what you may *not* do is repackage, redistribute, sublicense or sell the tool. Fine as an internal keyer; never ship it inside a product.
