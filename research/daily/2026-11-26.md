## 1. Verified on this machine (real runs, not README claims)

### `Remocn/remocn` 1,924★ MIT — **"shadcn for video": 940 Remotion components + a hosted MCP, MEASURED end-to-end**

This is the missing motion-graphics *library* the pipeline never had. It is not a renderer — it is a **shadcn registry**
whose components are copied into your Remotion project (you own the source), plus an agent skill and a hosted MCP.

- **Registry is real and countable**: `https://remocn.dev/r/registry.json` → **712,657 B, 940 items** (929 `registry:component`,
  11 `registry:lib`) — the README's "935" is 5 behind. An item resolves standalone: `counter-reveal.json` = **18,942 B / 2 files**
  (15,508-char `index.tsx` + timeline), deps `remotion` + `@remotion/google-fonts`, registry deps
  `@remocn/glide` + `@remocn/frame-rate` + `@remocn/timeline`.
- **Hosted MCP works with no key**: `https://remocn.dev/mcp` (Streamable HTTP) → `initialize` **0.49 s**,
  `tools/list` **0.44 s** = **4 tools** (`search_components`, `get_component`, `plan_video`, `preview_component`).
  Real calls: `search_components{query:"lab test explainer with big numbers and a clean chart reveal", vibe:"clean", maxLength:150}`
  → **0.61 s, 10 hit cards** each with name / length in frames / **Use** / **Avoid** / docs `.md` URL / install command;
  `get_component{counter-reveal}` → **0.46 s, 2,855 chars** of usage + props; `plan_video{brief:"20-second teaser for a lab
  force-plate dashboard"}` → **0.58 s, 15,562 chars** = a 6-beat storyboard (Hook / Positioning / Product reveal / Features /
  Proof / CTA) with ranked component picks **per beat**. An `archetype` arg overrides the recipe.
- **Real render** (fresh project, Remotion **4.0.547**, 146 npm packages): copied the 5 registry files, 3 lines of config →
  `remotion still` frame 60 = 937,607 B PNG; `remotion render` → **128 f 1280×720@30 H.264, 765,482 B, 6.6 s wall (~19 fps)**,
  `ffprobe` 4.267 s / 1.44 Mbps / `yuvj420p`. Frames inspected: giant "Beta" with the second line revealed through the letter
  counters → "Out now." on a gradient. Effect works exactly as documented.
- **Two pitfalls, both hit today**: (a) **Remotion's webpack does not honour `tsconfig` paths** — the components use `@/lib/remocn/*`
  imports, so bundling dies with `node_modules/@/…` resolution errors until `remotion.config.ts` overrides
  `config.resolve.alias["@"] = src`; (b) **npm install fails in this cron bash with `spawn C:\WINDOWS\system32\cmd.exe ENOENT`**
  because `ComSpec` is unset — `export ComSpec='C:\Windows\System32\cmd.exe'` fixes it (esbuild's postinstall is also blocked
  by npm 11's `allow-scripts` and needs approving).
- Its **craft rules** are the useful half of the skill (bans glow halos, gradient text, decorative ALL-CAPS, panels popping in on
  one frame, `Math.random()`, undefined durations, lorem copy). Independent of Remotion's official skills, which teach API
  correctness rather than what goes on screen.

### `fastvideo-project/dreamverse-harness` 115★ MIT — read, not runnable here

Open-source AI filmmaking on your own GPUs: an agent writes the film, locks character/location references, renders shots through
a **FastVideo server running FastH3**, and cuts takes on a timeline; every model is a provider plugin, skills are Markdown.
Node 22.19+/24 + pnpm 11.7 + ffmpeg. **Not 16 GB-fit**: the FastH3 8-step recipe wants **4 NVIDIA GPUs** (or 2× >80 GB GB200),
and FastH3 is a MiniMax-H3 derivative, so the **H3 territory licence (US excluded) applies**. Architecture reference, not a deploy.

## 5. Integration plan (next actions)

1. **Adopt Remocn as the motion-graphics layer.** Two entries: (a) point the agent at `https://remocn.dev/mcp` for search/plan/get
   (no key, read-only, <1 s per call) — cheaper than pulling the whole registry; (b) for a real job, scaffold Remotion
   (`npm i remotion@4 @remotion/cli@4`) and `npx shadcn@latest add @remocn/<name>`. **Set `ComSpec` before npm in cron bash and add
   the `@ → src` alias in `remotion.config.ts`** or the first bundle fails. Keep its craft-rules list as the review checklist;
   pair with the existing `scene-reviewer`-style gates (kinocut `release-checkpoint`, `givemotion check`).
2. **Do not add `screenpipe`** to any client or clinical pipeline without a licence review (commercial, source-available), and do not
   put camera-facing screen capture near patient data.
3. **`libpag` only as an app-side runtime.** If LabFlow/NeuroSync ever needs AE-authored micro-animations inside a native/web UI,
   PAG (Apache-2.0) is the shipping format; it is **not** a video exporter, so it does not replace Remocn in the render graph.
4. **DreamVerse = architecture reference only.** Its shape (agent + canvas + timeline + provider plugins + markdown skills) is the
   same contract as `video-autopilot-kit`, with the H3 GPU wall in front. Revisit if FastVideo adds an LTX/AMD-free backend.
5. **Add `yt-dlp` to the toolkit** (Unlicense, ledgered 11-24) as the acquisition stage for b-roll/reference/clip jobs,
and `cobalt` (AGPL) as the fallback when a site fights yt-dlp.
6. **Next rotation (11-27):** park `after-effects-topic`, `screen-recording-topic`; keep `fresh-month-movers` (2nd run) and
   `fresh-ltx`; add **`topic:remotion`** (the Remocn discovery says the Remotion ecosystem is a category with a real head — remotion-dev,
   templates, component registries) and **`topic:lottie`** (the runtime side: players/exporters for AE-authored motion).
