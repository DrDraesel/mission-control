## 1. Verified on this machine (real runs, not README claims)

### `edigeh/broll-mcp` 55★ MIT — **first REAL archive.org search** (the 11-24 run only handshook)
- `initialize` **2.93 s** → `tools/list` = 4 tools (`search_footage`, `inspect_item`, `extract_clip`, `get_provenance`).
- `search_footage{brief:"empty gym treadmill running workout b-roll", filters:{max_tier:2, license:"commercial_ok"}}`
  → **6.19 s wall, `upstream_requests:3`, 312 upstream matches → 100 ranked → 5 returned**, each with
  `tier`, verbatim `licenseurl`, `commercial_use:"allowed"`, runtime, colour, `has_shotlist`, `tile_url`, a
  human-readable `why` ("matched shotlist 'empty', shotlist 'running'; tier 1; h.264 available") and a `next_cursor`.
- **Strict input schema is a feature**: an extra `limit` field was rejected in **1 ms** with
  `{"error":{"code":"INVALID_INPUT","message":"… 'limit' was unexpected", "upstream_requests":0}}` — no silent no-op.
- **The real caveat, learned by running it**: tier-1 public domain is *archival/educational* — the top hits for a gym
  brief were **"Survival Under Atomic Attack" (1951)**, **"American Look" (1958)**, an atomic-alert film and a 1967
  consumer film. Excellent for documentary texture, useless for contemporary b-roll. Use tier 3/user uploads or your
  own footage when the brief is modern; keep tier 1 for archival/period sequences.

   that exposes a *local MCP server* and a structured plan format. Test in this order: download the 1.43 GB setup,

   use commercially, but 0.16+ source is closed — treat it as a product, not a forkable dependency.
2. **PeakCut vs autoclip vs ClipMint — pick the clipper by friction**: ClipMint = one .exe, zero setup; autoclip =
   Windows desktop + local Ollama analysis; PeakCut = source install but adds **live-stream clipping** and per-creator
   workspaces. Run all three on the same 20-minute lab/podcast recording before committing.
3. **broll-mcp: adopt with the tier caveat.** Wire it as an MCP server for archival sequences; for modern b-roll keep
   your own footage library. Its provenance JSON (written *before* the clip) is the model to copy in any asset fetch.

   the fallback if Editkin's closed-source path becomes a problem.
