## 2. Top finds today

### ⭐ 1. `0xShug0/audio.cpp` — 3,867★ Apache-2.0 — the local audio runtime the video pipeline was missing
One C++/ggml binary replaces the whole Python audio stack: **130+ model families / 200+ variants** covering **TTS, ASR, voice cloning, voice conversion, speech-to-speech, diarization, source separation, VAD, alignment, music generation (ACE-Step, YuE2, MiniMax Music3), MIDI and audio classification**.
- **Windows x64 prebuilt zips** (verified asset names): CPU 30.5 MB · **Vulkan-portable 82.1 MB** · CUDA 12.4 465.9 MB · **CUDA 13.3 277.3 MB** (+ separate cudart 575.5 MB — see the table above). Also macOS Metal, Ubuntu Vulkan/CPU, Docker images.
- **Scriptable three ways**: `audiocpp_cli` (batch from a text file or JSON request sequence, `--metrics` prints RTF), `audiocpp_server` (HTTP + **OpenAI-shaped `/v1/models`**, verified live), and the embedded WebUI with a **TTS narration workspace** (import script → split into passages → per-passage speaker/model/voice → compare takes → edit waveform and pauses → combine/export).
- v0.9.3 (2026-10-26) adds **LoRA across 11 models** with adapter strength + merge-to-GGUF, and perf presets measured at **−59…62 % RTF for ACE-Step, −33 % for MiniMax Music3, −27 % for Qwen3-TTS**.
Why it matters: narration + music + SFX + transcription for every faceless/marketing video currently runs through edge-tts (cloud), faster-whisper (Python) and a grab-bag of music repos. This is one native, Apache-2.0, CPU-or-CUDA runtime with a stable CLI — i.e. a direct pipeline dependency, not another app to babysit. 16 GB VRAM is not a constraint (the 5070 Ti runs the CUDA build; the CPU build already works).

### 2. `JimLiu/baoyu-design` — 5,374★ MIT — Claude Design, locally, as an agent skill (the Canva/After-Effects-adjacent gap)
Anthropic's Claude Design engine repackaged as a portable skill plus four "artifact" skills: `baoyu-design` (mockups, prototypes, wireframes, landing pages, decks), `claude-slides` (deck.json + one HTML per slide, present/retype/drag), `claude-design` (artboard canvas, playable prototypes), design-system + dataviz.
- **Import**: Figma `.fig` **decoded offline** · GitHub repo as a design source · existing HTML/CSS (reads the real stylesheets, lifts exact tokens).
- **Export**: standalone HTML · PDF · PNG (1×/2× zip) · **editable PPTX** · **MP4 video** · *send to Figma* · *send to Canva* · handoff to Claude Code.
- Install: `npx skills add JimLiu/baoyu-design [-g] [--agent claude-code|cursor|codex]`; Node 20+ (22+ for the dashboard skill), Python for the preview server. Pushed **today**; invisible to all 33 queries (design lane, 5th run in a row).
Caveat: MIT declared by the repo, but it repackages Anthropic product behaviour — fine for internal/client assets, don't resell it as your own product.

### 3. `D3voz/openjutsu` — 473★ MIT — video character/object swap on 16 GB, locally
"Drop a video and a character photo, press Generate." Built as a Next.js front end over **ComfyUI + MiniMax H3** (SAM 3.1 tracking, Qwen3-VL 8B describer, FLUX.3 Klein relight); gittrend ranks it **#5 AI-video repo, +210★ today**.
- Modes: simple 1-person swap · advanced 1–4 characters with roles · **object** change/remove/background · from-picture (FLUX poses your character into the frame, optional relight) · post: **fix faces** (redraws small faces close-up) and **fix colours** (DCTL tone mapper).
- **Tested on an RTX 4060 Ti 16 GB / 64 GB RAM** — H3 int8 streams from RAM. Requires **ComfyUI ≥ 0.41.2**.
Status: **cannot run here until the ComfyUI update** (local 0.25.0). This is now the third tool queued behind that single action.

### 4. `freemocap/freemocap` — 10,610★ AGPL-3.0 — free markerless motion capture from ordinary webcams
Python server + React GUI, installed with `uv venv && uv sync` (auto-selects **NVIDIA-GPU skellytracker on Windows**, `--no-default-groups --group cpu` for CPU-only). Multi-camera capture, skeleton tracking, Blender hand-off.
Why it matters here: it is the same class of measurement RunTrack does with MediaPipe, but multi-view and full-body, with an existing calibration + recording workflow. Also the cheapest way to get real human motion into 3D/animation without mocap suits (pairs with `UniMate` text→motion and `anymove` video→rig).

### 5. `brightbeanxyz/brightbean-studio` — 2,597★ AGPL-3.0 — self-hosted Buffer/Sendible replacement, 10+ platforms, official APIs
Schedule / approve / publish / monitor across **Facebook, Instagram, LinkedIn, TikTok, YouTube, Pinterest, Threads, Bluesky, Google Business Profile, Mastodon, DEV.to** from one multi-workspace dashboard; composer with per-platform overrides, Kanban idea board, unified social inbox (comments/DMs/mentions with sentiment), per-post analytics, media library with platform-optimized variants + alt text.
Self-host: Docker/VPS/local one-click (Heroku/Render/Railway also offered) — **all integrations talk directly to first-party APIs with your own developer credentials, no aggregator**. This is the publishing half of the JasMiamiMethod IG workflow that has only ever been done by hand or via paid tools.

### 6. `tannerhelland/PhotoDemon` — 2,415★ BSD — 22 MB portable Windows photo editor (XP→11)
Real permissive BSD (API says NOASSERTION), no install, runs from USB, 32-bit only (~2 GB image ceiling), pro-grade feature set. The lightweight batch/asset editor for Windows that doesn't need GIMP's footprint.

### 7. `ShareX/ShareX` — 40,528★ GPL-3.0 — the screen-capture lane's actual anchor (a 40k★ ledger gap)
