## 2. Top finds (new today)

### 2.1 `tangency-labs/solidcraft` — 4,852★ · Apache-2.0 · created 2026-10-07 ⭐ TOP PICK
"An open-source parametric 3D CAD application built in pure Rust." Sketch → constrain → feature timeline → rebuild on dimension change. Desktop + browser + **built-in MCP server so agents can model directly**. v0.15.0 shipped 10-17.
- **Windows:** x64 MSI 47.8 MB, portable zip 62.3 MB, plus arm64/x86 MSIs; unsigned (SmartScreen → More info → Run anyway); `winget install bherbruck.SolidCraft`.
- `bherbruck/solidcraft` currently redirects here (same repo) — use the `tangency-labs` slug.
- Why it matters: this is the ArtCraft pattern (clean-room, pure Rust, all platforms, MCP/CLI-drivable) arriving in the CAD lane. For the lab it means printable fixtures/rigs (camera mounts, plate adapters, electrode housings) modelled from a spec by an agent instead of by hand in Fusion 360's paid tier. Exports and the SolidCore kernel are worth checking before any print job.

### 2.2 `gatewai-dev/framefields` — 419★ · Apache-2.0 · npm `framefields@2.2.0` · created 2026-10-02 ⭐ TOP PICK
Code-first video, **rendered natively on WebGPU (Dawn/Metal/Vulkan/D3D12)** — explicitly *no Chromium, no Puppeteer, no DOM reflow, no screenshot pipeline*. TypeScript compositions (`Composition`, `Layer`, `LayerAnimation`), 50+ shader VFX (3D LUTs, curves, film grain, glassmorphism, blur), live localhost preview with waveform timeline, and **hardware-encoded MP4 output**. Agent skills install via `/plugin install framefields` or `npx skills add gatewai-dev/framefields` (its README names Hermes explicitly).
- Node ≥22, Windows D3D12 supported. Pushed today.
- Why it matters: our HyperFrames renders currently pay Chromium screenshot cost per frame. Framefields renders the same "video as code" idea 10× leaner and writes MP4 without a separate ffmpeg pass. Prime candidate to replace the render step in the faceless pipeline — *test on a 1080p60 3-second comp before adopting*.

## 4. Automation / editors / social assets

- **framefields** (2.2) is the headline for automation: TypeScript → GPU → MP4, no browser. Pair it with ffmpeg 9.0.2 for audio muxing and the whole Chromium-render step in the faceless pipeline disappears.

Closed source, but it sets the bar for what "AE replacement with agent control" now looks like — and it is free to use while our OSS options mature.
