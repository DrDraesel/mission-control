## 1. Verified on this machine — `yanghhu/ai-voiceover-studio` (0★, MIT)

A faceless-video **CLI + Python library**: write a Markdown script, drop `![](image.jpg)` per paragraph, and it produces voiceover, SRT, and a rendered MP4 with Ken Burns motion, transitions, a grade, a hook card, ducked music and word-highlighted captions — **in one ffmpeg graph, with free Edge neural voices, no key**. Published on PyPI as `ai-voiceover-studio` **0.3.0** (`py3-none-any`), created and last pushed **2026-11-07** — thirteen days old, zero stars.

Measured here (PyPI wheel via `uv`, not the repo):

| Step | Measured | Evidence |
|---|---|---|
| `uv run --with "ai-voiceover-studio[edge]" voiceover --version` | **`voiceover 0.3.0`**, 14 packages in **0.31 s** | exit 0 |
| `voiceover doctor` | ✔ Python 3.13.14 · ✔ **ffmpeg 9.0.2** (`libass` captions + cross-fades) · ✔ engine **edge** (free, no key) · ○ miragea/openai optional | "All set." exit 0 |
| `voiceover video --script examples/demo.en.md --style tiktok --music ambient` | **39.35 s · 1920×1080 · 7 shots/7 images · h264 + aac 44.1 kHz · 42,398,717 B** | `--json` manifest + ffprobe |
| custom 2-shot `myscript.md` `--vertical --style bold` | **9.0 s · 1080×1920 · 22 s wall** (edge TTS included) · 8,371,418 B | frame inspected: photo fills frame, caption word-highlighted, progress bar |
| offline path `--dry-run --vertical --images <folder>` | **40.6 s 1080×1920 in 23 s**, no network, no key | `provider: dummy` |
| bad `--images` path | **exit 2** + `{"error":{"code":"config_error","message":"No images or clips …"}}` | documented exit codes 0/1/2 |

CLI surface: `say / script / voices / video / doctor / task`; `--size 1080x1920`, `--vertical`, `--fps`, `--fit cover|contain`, `--subtitles burn|sidecar|none`, `--subtitle-source timing|recognize`, six caption styles (`auto,tiktok,bold,clean,minimal,box`), `--motion kenburns|none`, `--transition` × `--transition-style mix|fade|slide|zoom|cut`, `--grade cinematic`, `--hook`, `--music` + `--no-duck`, `--font`, `--voices` JSON/YAML speaker map, `--dry-run`, `--json`. Ships a drop-in agent skill (`skills/ai-voiceover/SKILL.md`) and a Python API (`Studio().render_script(...)` → audio/srt/segments).

**Why it matters:** it is the shortest path in the ledger from *copy* to a publishable vertical video with human-quality voice and karaoke captions, on Windows, with no key and no browser. **Caveats:** no CRF/bitrate knob — the encode is `yuvj420p` at 7–8.6 Mbps (42 MB for 39 s); re-encode with ffmpeg CRF 20 before delivery. Default size is 1920×1080 — pass `--vertical`. One author, one release, no tests observed in the wheel.

## 2. Top finds — `topic:design-tools` is a real category gap (12 tools, none ledgered)

The probe returned the design/web-asset layer the ledger had never covered — the same shape as `diagram editor` and `image upscaling` debuts. Sorted by what they remove from the pipeline:

### `shadcn-ui/lint` — 3,393★ MIT · an agent-first linter for Tailwind design systems
`@shadcn/lint` **0.2.5** on npm (MIT, verified). You declare what's allowed on your components; the lint error **explains the rule and the fix in your design system's vocabulary** — e.g. `"p-4" is not allowed on <Button>: <Button> owns its spacing. Use a size (sm, lg), or margin here…`. Works with **ESLint and Oxlint**, React/Svelte/Vue, Tailwind v4, shadcn/ui not required. **It is a plugin, not a CLI** — `npx @shadcn/lint` fails with "could not determine executable to run" (expected: no `bin`), you wire it into `eslint.config.mjs`. That makes it the deterministic **design-system gate** that pairs with keyline's `!overlaps` defect output: render → lint generated markup → re-render.

### `style-dictionary/style-dictionary` — 4,887★ Apache-2.0 · tokens → every platform
The build system behind design tokens: one source of truth → CSS vars, SCSS, JS, iOS/Android, JSON. Pushed 11-03. It is the missing *export* half of `google-labs-code/design.md` (ledgered 11-11), which lints DESIGN.md but emits only CSS vars/Tailwind/JSON.

### `megh-bari/pattern-craft` — 3,095★ MIT · background patterns for social/web assets
Copy-paste CSS gradients/patterns (grids, dot fields, meshes). Useful as a **background source** for keyline/takumi scenes — generate the CSS here, screenshot via takumi `raw` or Playwright, composite in ffmpeg. Not a renderer itself.

### `plasmicapp/plasmic` — 7,172★ MIT · visual builder → React code
Active (pushed today). Drag-and-drop builder that emits real React components into your codebase; the Canva-for-web-apps counterpart to keyline's static scenes. Heavy stack (Next.js + Postgres/Neon) — worth it only if a client needs a *site*, not an asset.

### `GoogleChromeLabs/ProjectVisBug` — 5,764★ Apache-2.0 · design QA in any page
Browser extension that lets you inspect/move/edit any rendered page ("FireBug for designers"). Zero API. Useful as a manual QA step on generated landing pages; last push 2026-08.
