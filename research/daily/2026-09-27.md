## 🏆 TOP FINDS TODAY

### 1. Modly — `lightningpixel/modly` ⭐ 7,837 · **MIT** · pushed 2026-09-19
**Local, offline image→3D mesh generation as a desktop app** (Windows/Linux/macOS; Windows installer `Modly-Setup-0.4.2.exe`, v0.4.2 2026-08-28). Runs entirely on your GPU; extension system swaps models: **Hunyuan3D 2 Mini (turbo/fast), TripoSG, Trellis2-GGUF**. "No Python setup" for users; API for scripting. → free replacement for sketchfab/3D-generation services for product mockups and scene assets.

### 2. VEED Open Edit — `veedstudio/open-edit` ⭐ 849 · Apache-2.0 (repo) · pushed 2026-09-22
**Open-source, agent-driven editing pipeline** (subtitles, motion graphics, slides, edit, render) released by VEED; install `npx skills add veedstudio/open-edit`. Ships CLI (`@veedstudio/openedit-cli`) with its own `install-ffmpeg` / `install-whisperx` helpers. ⚠️ Caveat: the **render engine binary is licensed separately (PolyForm Shield, source-available — not OSI)**, so review terms before commercial scale. Big name validating the "agent edits video end-to-end" pattern.

### 3. Explainer-video agent skills — `Vincentwei1021/anything2explainer` ⭐ 2,101 + `video-talkcraft` ⭐ 1,253 (both created Aug/Sep 2026)
- **anything2explainer** (created 2026-09-08): topic → **narrated black-canvas motion-graphics explainer** with TTS voiceover, subtitles, chapter progress bar. Node ≥18 + ffmpeg + python venv (`edge-tts==7.2.8` pinned — matches our local edge-tts), Remotion 4.0.507 render.
- **video-talkcraft**: voiceover-driven explainer studio — **word-level sync (median 20–40 ms — better than GPU forced aligners)**, 108 motion recipe cards, anti-slideshow camera system, SHOTBOOK storyboards, triple QA gates (sherpa-onnx alignment on CPU).
- ⚠️ **Both: custom license — non-commercial free; commercial use requires terms** (register/paid). Use as *pattern source* (their sync/QA discipline is worth copying) unless we clear commercial licensing.

### 4. Velorn — `VelornLabs/velorn` ⭐ 489 · GPL-3.0 · v0.3.36 (2026-09-26)
**"Open-source AI video workstation — a real editor for you, and 100+ MCP tools for your agent."** Windows installer + portable exe in the release ✓. Editor/captions/export/project-management work without ComfyUI; generation = production layer ON TOP of your local ComfyUI (uses its API, Bridge for open graphs). The most complete "open Premiere + agent" candidate so far.

### 5. Mazinger — `bakrianoo/mazinger` ⭐ 468 · MIT · pushed 2026-09-25
**End-to-end video dubbing pipeline**: download → transcribe → translate → voice-clone → dubbed audio/video in one command. `uv pip install "mazinger[all]"`; Python 3.10+ + ffmpeg; local LLM via Ollama; browser UI. → straight replacement for paid dubbing services for faceless localization.

### 6. ComfyUI's agent layer went first-party (ecosystem news)
- **Comfy MCP** (public beta): local server `comfy-mcp` (github.com/Comfy-Org/comfy-mcp) drives **your** ComfyUI over stdio MCP; cloud variant at `cloud.comfy.org/mcp` (paid). Comfy CLI + Comfy Agent (beta waitlist).
- The popular community server `artokun/comfyui-mcp` (⭐ 765) is **discontinued** — author points to official tooling.
- ComfyUI **v0.36.0** (Sep 15): **Generic Loops** (for/while/list in graphs), **Video Concatenate** node, FastH3, native YuE2 music, Marigold V2 (depth/normals/albedo), MiniMax-H3 VAE memory cuts. v0.35.0 added **File3DToMesh** (GLB/GLTF/OBJ/STL) + VideoTrim/Crop + WAN3-Prime.

### 7. ClipForge — `xixihhhh/clipforge` ⭐ 892 · AGPL-3.0 · pushed 2026-09-23
**E-commerce/UGC short-video factory**: one product photo → selling-point extraction + script + locked product fidelity + footage/voice/captions → Douyin/Kuaishou/Xiaohongshu/TikTok Shop ready clips. 0-cost batch, no watermark, local self-host. Also does topic→video. (Chinese-first docs.)

### 8. The Python video layer got two MoviePy alternatives (both verified)
- **libopenshot** `OpenShot/libopenshot` ⭐ 1,571 · LGPL-3.0 · pushed TODAY — C++ edit/animate/playback engine with **full Python bindings**, all FFmpeg formats, Windows build path. Not on PyPI (ships via OpenShot builds) — engine option for heavy timeline work.
- **movielite** ⭐ 72 · MIT — verified install (above). **vidiopy** ⭐ 11 · MIT — `pip install vidiopy` (PyPI 0.3.12) alternative.
- **ComfyUI-VideoHelperSuite** ⭐ 1,855 · GPL-3.0 — the standard video IO/switcher node pack for ComfyUI pipelines.

### 9. Velocut — `open-ribbi/velocut` ⭐ 454 · MIT · v0.0.2 (2026-09-17)
**Browser studio for editing video AND directing 3D scenes with AI**; ships npm SDKs incl. `velocut-mcp`, CLI, standalone ZIP; "Connect Codex". Very early (0.0.x) but the only tool combining NLE + 3D scene direction agentically.

### 10. Motionly — `COPPSARY/Motionly` ⭐ 87 · Apache-2.0 (CLI verified above)
**AI-native motion graphics editor**: `.motion` editable projects + agent skill library (12 focused skills: motion-dsl, easing, camera, composition, typography…), visual canvas/timeline, MP4 export; built with HyperFrames motion components. Small but exactly the "editable AI motion graphics" niche. Providers include opencode/Codex — adapt to Hermes manually.
