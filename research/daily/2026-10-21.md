## 2. Top finds

### 2.1 `cathrynlavery/diagram-design` — **59,304★ · MIT** ⭐ the ledger gap of the month
An agent skill that draws **editorial-quality diagrams as one self-contained HTML + SVG file**, in your brand. **45 diagram types**, "no shadows, no Mermaid slop".

- `npx skills add cathrynlavery/diagram-design`; works with Claude Code, Codex, Copilot, Cursor.
- **Brand onboarding**: point it at a URL (`Onboard diagram-design to https://yoursite.com`) and it pulls the **palette and fonts** — every diagram afterwards matches. For the JasMiamiMethod look (cream / ink / coral `#C94B31` / cobalt `#1683E0`) this is a one-command brand lock.
- Imports **drawio / Mermaid / Excalidraw**; exports **PNG / SVG**; output opens by double-click, no build step.
- Created 2026-04-16, pushed 10-20 — six months old, **no query we run could ever have found it** (it is a docs/skill repo with no matching topic vocabulary). This is the third consecutive week a 5-figure-star repo surfaced only via the web lane.
- **Pipeline position:** the missing piece for diagrams, process charts, comparison matrices, and "how it works" frames in reports, carousels, and landing pages — i.e. the asset type we were hand-building in HTML.

### 2.2 `deepbeepmeep/WanGP` — **10,848★** (v18.00, 10-11) ⭐ closes a 3-day open question
**The old slug `deepbeepmeep/Wan2GP` is gone** — it 301-redirects to **`WanGP`**, which is why `/releases/latest` returned 404 on 10-19 and 10-20. The project is very much alive, and v18 is a different class of tool than what we ledgered:

- **Kandinsky 6.0** added (Pro 30B / Lite 3B, distilled, synchronised audio incl. lip-sync), with a VAE the WanGP build claims is 2× faster than official.
- **Wan 2.2 Prism Video** — image-to-video *with audio*, natively up to 2K.
- **3D generation suite (new)**: Hunyuan3D 2.1 (mesh + PBR), TRELLIS.2 (textured PBR), TripoSG, TripoSplat (Gaussian splats), PartCrafter (per-part meshes); photo/video → scene via WorldMirror 2.0, MapAnything, Depth Anything 3, MoGe-2. Plus a **3D Viewer** (snap any view back as a start image) and a *Character Sheet* skill (3D character → turnaround sheet).
- **LTX 2.x VAE rewritten: 3× faster** — 20 s of 480p/24 fps in ~28 s on a 5090.
- Licence: Community Licence 2.0 (API reports `NOASSERTION`); free local use, outputs sellable, no SaaS resale. Windows one-click `.bat`; designed for low-VRAM ("GPU poor").

**Why it matters here:** it is the only single install on the list that produces *both* video and 3D assets in the 8–16 GB band, and it sidesteps the ComfyUI version problem entirely.

### 2.3 `deepfounder-ai/desigma` — **382★ · MIT OR Apache-2.0** (created 10-11)
Figma alternative written **100% in Rust**, native **Windows + Linux** desktop: frames, nested auto-layout, components + variants + instance overrides, prototyping with Smart Animate and variables, dev mode generating **CSS / Tailwind / SwiftUI / Jetpack Compose / React**, and **real `.fig` import** (kiwi container, deflate/zstd). tiny-skia CPU renderer with a 256 px tile cache; Inter ships in the binary; deck mode with PDF export.
- ⚠ **Early alpha and no release binaries yet** — building it means cargo + the Rust toolchain. Watch for the first signed build.

### 2.4 `openspline/openspline` — **270★ · MIT** (created 09-29, pushed today)
Self-hosted **realtime talking avatar** for voice agents: portrait + TTS audio → lip-synced video, 5-line Python SDK (+ Node), viewer/React/web-component embeds. Positioned against Tavus/Lemonslice per-minute pricing.
- ⚠ **Self-host GPU service is Linux/WSL2 + NVIDIA only** (`install.sh`, CUDA 12.8 for Blackwell / 12.6 older). No native Windows service. The MIT claim on the 90+FPS RTX 4090 demo is a Show HN claim, not measured here.

### 2.5 `BuilderIO/agent-native` — **7,471★ · MIT**
Agent-native design: the agent writes **self-contained HTML + Tailwind + Alpine** — the artifact *is* the screen, not a mock. Attach a design system and it generates in-brand. Honest about limits (not vector-native, no component library governance). Useful as the "design → real page" bridge; not a Figma replacement for illustration.

## 3. Video generation that fits 16 GB — status

**No new shortcut around the ComfyUI update.** Checked and closed:

- **`ltx-pipelines` on PyPI is *not* a LTX-2.5 route.** It exists (`ltx-pipelines` 1.0.0, `ltx-core` 1.0.0, `requires-python >=3.10`, deps `ltx-core, av, tqdm, pillow`) but has had **exactly one release, uploaded 2026-03-18** — it targets **LTX-2**, not 2.5. The `ltx-video` package is older still (0.1.2, 2025-07-25). Do not plan on it for 2.5.
- **The only verified no-ComfyUI path for 2.5 remains `LTX-Desktop` v1.3.1** (bundles its own Python env, needs ≥16 GB VRAM, 404.7 MB setup).
- **LTX-2.5 spec confirmation** (model card, via explainx 10-20): 22B diffusion transformer, native **multishot**, new diffusion video decoder, Gemma 4 12B text encoder + prompt enhancer, optional duration predictor, **8-step distilled**; needs Python 3.12+ / CUDA 12.7+ / PyTorch ~2.7; low-VRAM mode = **fp8-cast + CPU offload**. Licence: **LTX-2.x Community** — free commercial use **under $10M annual revenue**, paid agreement above; fine-tune transfer may need a paid licence. No published benchmarks.
- **Q4_K_M 15.7 GB remains the plan** for this card once ComfyUI is current (Q3_K_S 12.6 GB if tight). WanGP v18 is the fallback if the ComfyUI update stalls again.
