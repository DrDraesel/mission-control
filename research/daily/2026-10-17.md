## 2. Top finds (new today)

### 2.1 `lemomo-ai/lemo-opuscar` — 2,810★ · MIT · created 2026-09-26 ⭐ TOP PICK
"51 film styles, each with a short film made entirely in code." Canvas/WebGL pages rendered frame-by-frame, written stereo score from free sample libraries, TTS narration. **No video generation, no stock footage, no GPU model.**
- Install: `claude plugin marketplace add lemomo-ai/lemo-opuscar` → `claude plugin install lemo-opuscar@lemolab`; the skill's `scripts/setup.sh` clones the library to `~/lemo-opuscar` (git-bash OK on Windows).
- Requires Node 20+, ffmpeg, Python 3.11+ (or uv) — **all present here**.
- Why it matters: this is the *faceless-content engine* pattern the pipeline wants — pick a style, hand it a story, get a 40–60 s film with narration and music, fully local, deterministic re-renders. Style library doubles as a design system (51 `STYLE.md` prompts you can lift into your own HyperFrames/Remotion work).
- Caveat: styles tuned for Claude Opus 5.5; other models may not reproduce them. Third-party demo assets keep their own licences.

### 2.2 `walterlow/freecut` — 2,270★ · MIT · freecut.net
Browser multi-track NLE: WebGPU effects/compositing/transitions/masks + **GPU color scopes (waveform, vectorscope, histogram)**, WebCodecs preview & export, OPFS + File System Access API workspace. Local-first — no uploads. Runs in Chrome/Edge on Windows with zero install; self-host needs Node 22+/npm 11+.
- Why it matters: a free Premiere-lite review surface for clients/patients without installing anything; also a reference implementation for WebGPU compositing if we ever take RunTrack/NeuroSync reporting into video.

### 2.3 `alexgreensh/anidoodle` — 972★ · Apache-2.0 · created 2026-09-22
"Hand-drawn art, written as code." Illustrations, drawing timelapses, films, explainers, interactive web art in 32 styles. One deterministic canvas core, **four render backends: playwright / html-player / remotion / hyperframes**. Ships a written-score music engine (21 styles) and `launch.mjs ship` QC (SRT/VTT captions, A/V sync, peak level, text-overflow frame check).
- Install: scaffold a project, `npm install`, `npx playwright-core install chromium`; Node 20+, ffmpeg for motion.
- Why it matters: the hand-drawn/whiteboard-explainer lane without a drawing tablet, and it renders through **HyperFrames** — direct fit with the existing stack. The `ship` QC gate is exactly the kind of pre-delivery check our pipelines lack.

## 3. Video-gen fit for 16 GB VRAM

| Route | Status today |
|---|---|
| **LTX-2.5 (ComfyUI, int8)** | Official floor is **32 GB VRAM** (docs.ltx.io, ComfyUI-LTXVideo), **but** a measured run on an RTX 4070 12 GB: 736×1280, 24 fps, 5 s → **11.4 GB peak VRAM, 45 GB system RAM, 6 min 55 s** (source: `TF6cool/comfyui-video-model-vram`, CC-BY-4.0, numbers attributed). The system-RAM requirement is the real gate on our box. |
| **LTX Desktop** | Local gen on Win with **≥16 GB VRAM**, LTX-2.5 Fast default, **gated HF weights** (sign-in + licence), ~45 GB download minimum (up to ~160 GB full). |
| **Wan2GP** | Still the "GPU poor" route: 6 GB min, LTX-2 @ ~10 GB, one-click .bat, WanGP Community License 2.0. |
| **FreeVideo (H3)** | 8 GB-VRAM claim, VDN-H3 weights under custom OpenVDN agreement. |
| **Kandinsky S2V 1.0** | Lite 2B / Pro 21B, MIT, paper 10-15 — **GitHub repo linked by the paper is 404 as of today**; HF collection live. Watch, do not plan around it. |
| **ComfyUI local install** | Still v0.25.0 vs upstream v0.39+ — the update remains the single blocking action for LTX/Kandinsky/H3 nodes. |

Verdict: no new model work justified today. The measured 12 GB LTX-2.5 numbers are the first credible evidence that a 16 GB card can run it **if** the box has ≈48 GB RAM — worth a one-off trial *after* the ComfyUI update.
