## 🏆 TOP FINDS TODAY (install-worthy)

### 1. HyperFrames — `heygen-com/hyperframes` ⭐ 53,003 · Apache-2.0 · pushed TODAY
**"Write HTML. Render video. Built for agents."** HeyGen's open-source HTML→MP4 framework. Author an `index.html` (timing lives in `data-*` attrs), renderer seeks each frame in headless Chrome (Puppeteer) and encodes with FFmpeg. **Deterministic** — same input = same output = CI/automation friendly. Inspired by Remotion but Apache-2.0 (no paid tier) and plain HTML (no build step).

Built-ins that directly attack our gap (motion graphics, animated backgrounds, kinetic typography):
- `npx hyperframes tts` → local **Kokoro** TTS, 54 voices, 9 languages, no API key
- `npx hyperframes transcribe` → Whisper **word-level captions** (karaoke style), imports SRT/VTT
- Transition/VFX registry: 3D, blur, glitch, light leaks, WebGL shader warps, whip pans
- Social overlays (YouTube/TikTok/IG/X), lower thirds, audio-reactive motion, voiceover ducking/EQ
- `remove-background`, animated charts/chart-races/maps, MS-style notifications
- Agent skills: `npx skills add heygen-com/hyperframes` (Claude Code/Codex/Cursor; 21 skills, router installs workflows on demand)
- Render targets: local, Docker, AWS Lambda, HeyGen cloud (optional)

**Install:** Node 22+ ✓ + FFmpeg ✓ → `npx hyperframes init my-video` → `preview` → `render`.
**Reference productions:** `heygen-com/hyperframes-launches` (553★, HeyGen's own launch videos as source).
**Ecosystem signal:** at least 4 repos found today already build ON HyperFrames (MotionClone, NullMotion, bang-motion, hyperframes-student-kit, OpenMontage runtime). This is the format to adopt.

### 2. Chatterbox — `resemble-ai/chatterbox` ⭐ 26,555 · MIT · Python
Human-sounding TTS + zero-shot voice cloning (5–10s reference) — the fix for robotic gTTS.
- Emotion exaggeration control + `[laugh]`/`[sigh]` tags (Turbo). Vendor blind test: preferred over ElevenLabs 63.75% (their own eval — signal, not proof).
- Variants: **Turbo** (350M, low-latency), **Nano** (110M, CPU 3x realtime!), **Multilingual V3** (23+ langs).
- 0.5B fits 16GB VRAM easily. `pip install` + `ChatterboxTurboTTS.from_pretrained()`.

### 3. Kokoro-82M — `hexgrad/kokoro` ⭐ 9,000 · Apache-2.0
82M-param TTS, 54 voices, 8 languages, CPU-realtime, `pip install kokoro`. TTS-Arena Elo ~1056 (crowd blind votes). Also embedded in HyperFrames' `tts` command → fastest drop-in upgrade for voiceovers with zero GPU cost.

### 4. MotionClone — `blixvip/MotionClone` ⭐ 330 · no license yet ⚠️ · created 2026-09-10
**Reference video → editable motion graphics.** Local Windows app + online studio. Import a clip (X/YT/Vimeo/local, ≤120s/250MB) → Codex+ChatGPT rebuilds it as an editable project → side-by-side compare → export MP4 **or editable HyperFrames project** (`npm run preview`/`render`).
- Prereqs we already have: Git, Python 3.11+, Node 22+, FFmpeg, Chrome, Codex CLI.
- ⚠️ No project license assigned; reconstruction is approximate (tiny text/complex 3D need rework). Use for style-cloning own-format assets.
