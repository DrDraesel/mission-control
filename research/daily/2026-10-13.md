## Top find #1 — Hypit (viral-video cloning agent skill) — `hypit-ai/hypit`

- **What it is:** an agent skill (Claude Code / Codex) + CLI + "SVML" word-anchored video language. Drop in a reference video → the agent clones the *whole workflow* (shots, pacing, captions, B-roll, effects), not a script breakdown. Rewrite a line → timing re-flows. Also builds from scratch via `/hypit Make a ranking video ...`.
- **Cost model:** free to use; **generation models are optional** — a workflow can compile captions + motion graphics + code-rendered visuals **locally with no model calls**. Cloud examples land at ~$1.05–1.15/clip. Renders through 64 headless Chromium processes (local CPU/GPU).
- **License:** modified Apache-2.0 — free for your own org's commercial work (incl. client work, single-tenant); **no multi-tenant SaaS / no commercial redistribution**; keep the branding in CLI surfaces. **Outputs are yours** (license imposes no terms on created videos). Fine for local production and client deliverables; flag before any hosted product.
- **Install:** `npx skills add hypit-ai/hypit -g`; needs Node ≥22.15 ✓ (v26.3.0), pnpm 10.33 ✓ (11.7.0), WhisperX for word alignment (pip; ffmpeg ✓). Windows OK (pure Node + Chromium).
- **Why the sweep missed it:** created 2026-07-29 — *before* the fresh-agents window (`created:>2026-08-25`) and no topic query matches its vocabulary ("clone"). Caught via facelessreels.video references + Trendshift.
