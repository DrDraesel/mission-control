## 1. Verified on this machine — `keyline-dev/keyline` (6★) is a working agent design engine

The strongest component of the day is a **6-star** repo, found only through the `canva-alternative` topic on the web lane. `keyline-mcp` is a single Rust binary on **Skia** that renders a JSON design scene to social/ad sizes, video and PDF — **no headless Chrome, no Puppeteer, no browser anywhere**. Licence **FSL-1.1-ALv2** (free for any use except building a competing engine; converts to Apache-2.0 after two years — same shape as raea).

Installed from the release asset `keyline-mcp-v0.8.1-windows-amd64.zip` (**14.9 MB**), extracted to a folder, no installer. Measured here:

| Step | Measured | Evidence |
|---|---|---|
| `keyline-mcp.exe render scene.json --out out --preview` | **2 sizes** (1080×1080 + 1080×1920) in **0.47 s wall** | 32 KB + 36 KB PNGs, frame inspected |
| layout check (same run) | **`!overlaps` defect caught with numbers** — `text1 "Mission Control" 108,395 864×290 120px`, `text2 108,514 864×53 44px`, plus `empty y 657–1080 (39%)` | the engine reports *what is wrong and the measurement that fixes it*, not a screenshot |
| `--format mp4` on an animated scene (`duration 3`, `fps 30`, `enter: fade-up`, `animate: scale [1,1.08,1]`) | **90 frames 1080×1080@30, h264, 148,659 B in 1.48 s** (~61 fps) | ffprobe: h264 / 1080×1080 / 90 frames / 3.000 s |
| `--format pdf` at `a4-portrait` | **17,668 B `%PDF-1.4` in 68 ms** | file header checked |
| font handling | Inter 500/700/800 bundled; any Google Fonts family auto-downloads + caches | render log |
| error UX | unknown field → *lists every valid field for that layer type* and suggests the nearest name | `unknown field(s) motion for text layer; … any layer: … enter, animate` |

Scene format is one master size + target `sizes` (presets: `instagram-square/story/portrait`, `facebook-feed`, `linkedin-post`, `x-post`, `youtube-thumbnail`, `iab-*`, `a4-portrait`), with tokens (`{{brand}}`), styles, components, grids/flex-ish frames, per-size `media` overrides, 5,000 Lucide/Font Awesome icons by name, and GSAP-style `animate` tracks. Video needs `ffmpeg` on PATH (found: 9.0.2). It is also an **MCP server with 6 tools** for Claude Code/Cursor/Codex.

**Why it matters:** this is the first renderer in the ledger that produces *every* social size, *video* and *print PDF* from **one structured scene**, with a machine-readable defect list an agent can act on — i.e. the Canva replacement for automation, not for a mouse. Caveats: 6★ and one author (v0.8.1, last push 10-26); FSL blocks shipping a competing design engine; layout is keyline's own, not browser-exact, so existing HTML templates do not port.

## 2. Top finds

### `zhouxiaoka/autoclip` — 10,945★ MIT · the local OpusClip, with a real Windows build and a CLI

Found on GitHub Trending today; **absent from the ledger**, and it is the most complete clipper seen so far. Long podcast / interview / course / talking-head video → **up to 10 scored clips per platform** (Douyin, Xiaohongshu, TikTok, Reels, Shorts, YouTube, Bilibili), each with cover, title, description, hashtags and a **ZIP publish pack**. Cutting, framing and rendering run locally; **analysis is model-agnostic** — any OpenAI-compatible endpoint, or **Ollama / LM Studio locally with no API key**; subtitles come from author captions, **local Whisper / SenseVoice**, or optional cloud ASR.

## 3. Ledgered but not evaluated — `toyxyz/toyxyz_RGBMocap` went trending today

`RGBMoCap` has been in the ledger since the 11-16 `mocap` probe and was never run. Today it **gained +279★ in 24 h** (1,946★ total, 259 forks, created 10-26) and shipped a new release at 10:00 ET. It is a **native Windows** app that turns ordinary video into editable human animation: ExMR / FlowHMR / GVHMR inference, contact correction, multi-person takes, retarget to **Mixamo FBX, VRM, PMX**, export **FBX / BVH (Blender or 3ds Max Biped) / VMD**, stream bones into **Blender** (add-on) or **Unreal Live Link**, and write portable Blender projects. Licence: **MIT for its own code**, third-party models keep their own terms (MAMMA and PromptHMR need a licence review; SAM 3.1 tracking costs extra VRAM). Install is `git clone` + `install.cmd` with Python/Blender/FFmpeg prepared; NVIDIA GPU (8 GB class per the author's promo, SAM 3.1 higher).

**Why it is on this report:** it is the first **video→FBX mocap** path in the ledger that is Windows-native and agent-installable, and it sits directly on the RunTrack/Bertec lane — a treadmill or squat clip could become a rigged 3D animation for patient education, with the joint angles already computed by RunTrack as the ground truth to compare against. Next step is a 10-second trial clip, not an install spree.

## 9. Integration plan

1. **Install `keyline` as the social-asset renderer.** 14.9 MB binary at `~/.local/opt/keyline/`, `~/.local/bin/keyline.cmd` shim, one JSON scene per campaign → every size + MP4 + PDF in under 2 s. Use it for carousels, ad sets, episode cards and clinical one-pagers; keep `takumi` for HTML-derived reports. Its `!overlaps`-style checks are the gate our pipeline has been missing for text-heavy layouts.
2. **Adopt `autoclip` for clip repurposing.** `uvx autoclip-mcp` works today; add local Whisper (one click in the desktop app) and point the provider at Ollama. This replaces an OpusClip subscription with a MIT pipeline that renders locally.
3. **Trial `RGBMoCap` on a RunTrack clip.** Ten seconds of treadmill footage → FBX in Blender, then compare bone trajectories against RunTrack's joint-angle output. If it holds, it is the patient-education 3D layer for both RunTrack and Bertec.
4. **Do not adopt `doory`** for client work without reading the Attribution Assurance License; `opentempl`/`OpenDesign` are the MIT alternatives for human editing.
5. **Unchanged #1 action: update ComfyUI** (0.25.0 → 0.46.x). Twenty-one versions of blocked tooling is still the largest single lever in the ledger.
