## 1. Verified on this machine — the SAM family, measured

`facebookresearch/segment-anything` (**55,146★, Apache-2.0**) had never been in the ledger after two months of sweeps, because no query ever said "segment anything". Ledgered today with the rest of the family. Measured on the real thing rather than quoted from a paper:

Environment: `projects/avatar-lab/.venv` (torch **2.11.0+cu128**, RTX 5070 Ti), `pip install git+…/segment-anything`, checkpoint `sam_vit_b_01ec64.pth` **375,042,383 B**, input = a frame pulled from a real RunTrack upload (`runtrack/data/uploads/20261019_125600_…mp4`, 4320×7680 → 1080×1920).

| Step | Measured here |
|---|---|
| model load (vit_b, fp32, CUDA) | **0.51 s** |
| image encoder `SamPredictor.set_image` @1080×1920 | **274 ms** |
| point-prompt decode (centre point) | **113 ms**, IoU **0.988**, mask **81,294 px** |
| `SamAutomaticMaskGenerator` 16×16 grid | **30 masks in 0.50 s = 17 ms/mask** |
| peak VRAM allocated | **3.20 GB** |
| output | `sam_overlay.png` — green boundaries trace the runner's silhouette, the treadmill deck, the sofa and the floor box (frame inspected, not a black frame) |

**Why it matters:** 3.2 GB and 274 ms per 1080p frame means segmentation is now a *cheap* pipeline step on this box — subject cutout for 9:16 reframes, product masks for social cards, and clinically, organ/region masks. The full automatic-mask pass costs half a second per frame, so "mask everything, then decide" is affordable at 1080p; at 4K expect ~4× encoder time. SAM 2 (video, memory-based tracking) is the upgrade path — note its README says **Windows is "strongly recommended" via WSL**, whereas SAM 1 ran natively here with zero friction.

Also smoke-tested: **`npx -y agent-screenplay@0.1.7 --help` → exit 0**, commands `record / render / style / check / login / mcp / guide / schema` (npm `agent-screenplay` 0.1.7 MIT, 9 versions).

## 7. Integration plan

1. **Add SAM as the mask step** (`segment_anything` + vit_b, 3.2 GB, 274 ms/frame): subject lock for 9:16 reframes, cutout plates for social cards. Use SAM 2 only if tracking through occlusion is needed (and budget WSL).
2. **Wire OpenScreen CLI** as the demo-recorder (`record --json` → `.openscreen` → `export`), and keep `agent-screenplay` for spec-driven product walkthroughs. Replace the "Screen Studio" spend; log both as MIT.
3. **Clinical**: trial **TotalSegmentator** on one de-identified CT (CPU is fine) and export `--output_type dicom_seg` — the first DICOM-filable segmentation step available to the lab apps. Pair with 3D Slicer for review.
4. **Design**: adopt `cinetic`'s `copy-check.py` idea into our HyperFrames pipeline even if we don't adopt the skill wholesale — a copy gate before render is cheaper than a re-render.
5. **Unchanged #1 action: update ComfyUI** (0.25.0 → 0.45.x). Twenty versions of blocked tooling is now the largest single lever in the ledger.
