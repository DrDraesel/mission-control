## 🏆 TOP FINDS TODAY

### 1. VoiceStudio — `debpalash/VoiceStudio` ⭐ 35,650 · AGPL-3.0 · Python · pushed TODAY
**The open-source, fully-local ElevenLabs alternative.** Voice cloning, voice design, **video dubbing, dictation, transcription, audiobook creation — 646 languages**. Windows/macOS/Linux/Docker install docs; ships a **Local API + MCP** for automation; agent skills included. Release channel `v0.5.6` (2026-09-23) with Windows (win32-x64) electron builds.
→ Direct upgrade path for the robotic-voiceover problem: clone one brand voice, dub/dictate every video, no per-character fees, fully offline.

### 2. Graphite — `GraphiteEditor/Graphite` ⭐ 27,364 · Apache-2.0 · Rust · pushed TODAY
Professional-grade open-source **2D design editor** (vector + raster, node-based procedural workflows) — the strongest "free Canva/Illustrator replacement" in the sweep. Cross-platform desktop (+browser). Actively developed (pushed today). Great fit for social/marketing graphic assets and procedural template generation.

### 3. Duix-Avatar — `duixcom/Duix-Avatar` ⭐ 15,585 · custom license* · C
**Fully-offline AI avatar / digital-human toolkit** for Windows (also Docker on Ubuntu 22.04). Clones appearance + voice for talking-head video generation, open APIs.
*License: free commercial use including global use — but **>100,000 users or >$10M annual revenue requires a signed commercial agreement**. Last push 2026-04-21 (slower cadence — verify before betting on it).

### 4. Voice-model cluster (the TTS/dubbing layer, all verified today)
- **Qwen3-TTS** `QwenLM/Qwen3-TTS` ⭐ 13,548 · Apache-2.0 — official Alibaba Qwen TTS series (voice clone/design, stable + streaming); Python package `qwen-tts`, weights auto-download from HF/ModelScope. Backbone used by several tools below.
- **yovoice** `leemysw/yovoice` ⭐ 139 · Apache-2.0 · NEW (created 2026-09-15!) — Windows + macOS desktop app: local TTS, voice cloning, emotion control; runs **IndexTTS 2.0/2.5, VoxCPM2, OmniVoice, Qwen3-TTS via audio.cpp**; CUDA on Windows; `.exe` installer.
- **Qwen3-Audiobook-Converter** `WhiskeyCoder` ⭐ 1,097 · MIT — PDF/EPUB/DOCX/TXT → audiobook via Qwen3-TTS (pattern reference for long-form narration).

### 5. nexu-io HTML-video stack — `nexu-io/html-video` ⭐ 4,617 + `nexu-io/html-anything` ⭐ 8,951 · Apache-2.0 · pushed TODAY\*
**"HTML becomes video — on your laptop."** Agent-driven local MP4 rendering (headless Chromium + ffmpeg/libx264, no cloud, no per-clip fee). Pluggable engine architecture with the **HyperFrames engine fully wired**; 21 license-clean templates (data viz, product promos, social shorts, explainers, kinetic type, transitions). Explicitly supports 14 agent CLIs **including Hermes**. Companion **html-anything** = agentic HTML editor with one-click social exports (X/Weibo/Xiaohongshu 2× PNG, WeChat paste-ready CSS).
\*html-video last pushed 2026-06-21; html-anything pushed 2026-09-15.

### 6. pireel — `pireel/pireel` ⭐ 1,232 · AGPL-3.0 (+Apache-2.0 agent plugin) · TS · pushed 2026-09-18
Open-source **CapCut/ChatCut alternative** — canvas + timeline editor for humans, **drivable end-to-end by any AI agent over MCP**. Web try + self-host; the agent plugin is separately Apache-2.0.

### 7. Editor corner: Friction + Premation (AE-class, open source)
- **Friction** `friction2d/friction` ⭐ 1,811 · GPL-3.0 · C++ · pushed 2026-09-17 — real motion-graphics app (keyframes, graph editor, vector/raster). **Windows installer available: `friction-1.0.0-rc.3-setup-win64.exe`** (latest GH release). The most usable free AE-style tool today.
- **Premation** `isroil01/premation` ⭐ 50 · AGPL-3.0 · pre-1.0 — brand-new AE-style motion editor (Electron, WebGPU render engine, local ffmpeg export, BYOK AI assistant). Website tracks v0.7 (177/183 effects on GPU). Too early to adopt; watchlist.

### 8. Maestro — `Blizaine/Maestro` ⭐ 633 · license: NOASSERTION ⚠️ · Python · pushed TODAY
**One-click local AI creative studio + director + non-destructive multi-track editor**: image/video/audio gen optimized for **LTX-2.5 + MiniMax H3**, LLM-directed workflows (incl. beat-aware music-video shot planning), **auto-detects GPU/VRAM and picks quantization profiles**, OOM-recovery banner. Caveat: some bundled models carry research/eval licenses (Qwen Image 2.1 commercial use = separate Qwen license) — check per-component before commercial output.
