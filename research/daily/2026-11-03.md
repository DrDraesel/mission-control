## Top finds

### 1. The audio-editor probe exposed two famous-tool ledger gaps
- **mifi/lossless-cut — 45,660★ GPL-2.0** (v3.70.2, 2026-10-28). The "swiss army knife of lossless video/audio editing": stream-copy cuts, keyframe snapping, batch export, ffmpeg command export, no re-encode. Windows: `LosslessCut-win-x64.7z` **144.7 MB** (portable). This is the tool to put in front of any clip-trimming step in a pipeline — it had never been in the ledger in 5+ weeks of sweeps because no query names "audio editor".
- **WyattBlue/auto-editor — 5,741★ Unlicense** (v31.8.0, 2026-10-30). Automatic silence/dead-air removal, `--edit audio:threshold=4%`, motion/velocity modes, `--export` to Premiere/Resolve/FCP XML. Windows `auto-editor-windows-x86_64.exe` **43.4 MB**. Unlicense = no attribution constraints. Verified working above.
- **bugbakery/audapolis — 1,905★ AGPL-3.0**. Spoken-word audio editor where you edit *text* and the audio follows (auto transcription). Windows `audapolis-win-x64-0.3.1.exe` 176.9 MB, but last push 2026-06 and last release 2025-11 → maintenance limbo; reference architecture for "edit the transcript" UX.
