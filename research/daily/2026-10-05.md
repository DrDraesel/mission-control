### A. mutonby/openshorts — 6,118★ · MIT · self-hosted AI video platform, 3 tools in one (pushed today)
The biggest find of the run and a full "clip factory" platform: **Clip Generator + AI Shorts
(UGC videos with AI actors) + YouTube Studio** in one self-hosted app. Pipeline: yt-dlp ingest →
moment detection → FFmpeg composite with subtitles + hook overlays (Gemini key for the AI analysis

CPU, **~50 s on an NVIDIA GPU**. Origin: Reddit (Dec 2025) — exploded to 6.1k★. Sibling
**faris-sait/openshorts (114★)** is a mirror of the same project (its README links back to
mutonby). This is the open platform answer to Opus Clip at platform scale.

## 4) moviepy revisit (rotation item)

- Current: **MoviePy 2.2.1**. No new release; but active maintenance on the perf regression
  (issue #2395: v2.x resize-heavy pipelines can run ~10× slower than v1.0.3 — root cause: dropped
  OpenCV, Pillow resize ~8ms vs OpenCV <1ms). **PR #2499 re-introduces OpenCV** for image ops;
  maintainer also started **GPU acceleration (CuPy) + CPU parallelization** work.
- Practical guidance for the pipeline: keep MoviePy for composition, avoid per-frame
  `resize/rotate` in v2 where possible (prefer `target_resolution` on load), export via NVENC
  (`h264_nvenc`) and let FFmpeg do the heavy lifting. MovieLite (already tested here) remains the
  CPU-perf alternative. Re-check when OpenCV PR merges.
