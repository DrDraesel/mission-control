### `kajisho5/ffmpeg-skill` 4.7.0 — 10,052★ MIT — **the 42-tool FFmpeg engine your agent calls**
- `npx ffmpeg-skill --help` → installer for Claude Code / Cursor / Codex / MCP, exit 0. `--dir ./skills` drops **46 scripts** into a custom dir (no agent needed).
- `npx ffmpeg-skill doctor --json` → **every capability `usable: yes`**, ffmpeg **9.0.2** auto-found, exit 0. Tools cover: probe, cut, join, fit, silence, captions/karaoke, graphics, overlay, color/LUT, HDR, loudness, sync, multicam, stabilize, scenes, speedramp, sequence, verify, waveform, redact, proxy, batch, render.
- Ran on a synthetic 6 s 640×360 + 440 Hz tone clip:
  - `fit.py --aspect 9:16 --fit crop` → **202×360**, exit 0 — and it *refused to upscale*, printing `--aspect alone keeps the source's size … --width 1080 gives the usual delivery frame (enlarged 5.3x)` plus `warning: the crop keeps 32% of the picture`.
  - same + `--width 1080` → **1080×1920, 6.000 s, exit 0**.
  - `loudness.py -I -14 --tp -1` → measured **−41.8 LUFS / TP −37.6 dBTP**, output **−14.0 LUFS / TP −9.9 dBTP**, exit 0.
- Every run **prints the exact ffmpeg argv** it executes — auditable, reproducible, offline, no keys. SPEC contract derives each MCP `input_schema` from the same argparse parser (CI fails on drift). npm `ffmpeg-skill@4.7.0`.
