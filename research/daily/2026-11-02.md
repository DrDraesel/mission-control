### 2.2 `Zarxrax/Sammie-Roto-2` — 491★, GPL-3.0 — **new, and the best Windows matting GUI**

Cross-platform desktop app (NiceGUI) for AI masking of video: SAM2 segmentation, MatAnyone/MatAnyone2/

- **Latest release v2.5.0 (2026-10-04)** → asset **`Sammie-Roto-2.5.0.zip`, 6.8 MB, HEAD 200**, 2,170 downloads.
- Windows path is the documented one: extract anywhere writable → **`install.bat`** (creates its own venv,
  downloads models) → `run_sammie.bat`. AMD-on-Windows preliminary support since 2.4.1.
- Why it beats MatteDesk for us today: MatteDesk's generative stage wants **24 GB**; Sammie runs the
  SAM2+MatAnyone path on a 12–16 GB card, needs **no ComfyUI**, and is installable right now.

  bundled models is the non-commercial cluster above — treat as a local/creative tool, not a resale tool.

## 7. Query-lane lessons (for the rotation log)

1. **`matting stars:>200` works and is the model for new probes**: 52 results, 13 new, and it surfaced two
   famous-tool gaps (HivisionIDPhotos 21.7k★, RobustVideoMatting 9.6k★) that 20 prior runs never touched.
   The word is unambiguous to a Python/CV developer — exactly the condition that made `diagram editor` and
   `motion capture` pay off.
2. **`video compositor stars:>200` is dead on arrival — 4 results total**, and they are
   `mpvpaper` + `phonto` (both *Wayland wallpaper* programs whose descriptions say "for wayland
   compositors"), `Seriously.js` (2011) and the BBC's 2015 HTML5 compositor. The word "compositor" belongs
   to Linux display servers in GitHub's vocabulary; **adding "video" does not disambiguate it.** Retire
   after this one run — second confirmation of the 10-31 finding.
3. `fresh-ltx` returned **0 new** today (48 results, all ledgered) — the LTX ecosystem has stabilised; the
   value in that lane is now in *recipes*, not repos.
4. **PyPI name collisions are getting worse in the agent-tool lane**: `earshot` on PyPI is an unrelated VAD
   library. Always resolve `pypi.org/pypi/<name>/json` → `info.project_urls` before promising a pip route.

## 8. Integration plan (ranked, concrete)

1. **Install `pymatting` into the IG/asset pipeline** — it is 6 packages, MIT, CPU, sub-second. Use it to
   cut the subject out of a still and drop it on brand colour, instead of hand-cutting in an editor.
   Success criterion: one `jasmiami-social` post regenerated with a real alpha cut-out, PNG-24 output.
2. **Install Sammie-Roto-2 v2.5.0** (`Sammie-Roto-2.5.0.zip`, 6.8 MB, `install.bat`) and run one RunTrack
   session stills sequence through SAM2 → MatAnyone. This is the cheap matte path that does **not** need
   the ComfyUI update; keep MatteDesk for the generative LTX alpha edge once a 24 GB card exists.
3. **Add `earshot critique` as an audio gate** in the video pipeline — install from source (numpy-only core),
   then score one existing render. The pipeline currently has video gates and no audio gate at all.
4. **Wire `mg-styles-15` style prompts + `motion-prompt` into the motion skill** — 15 full style decks with
   source and synthesised scores is the vocabulary layer the motion lane has been missing.
5. **Port mg-styles-15's `renderAt(t)` → headless Chrome → ffmpeg** shape into our renderer; it matches the
   "avoid complex ffmpeg filters, composite frames" rule already in use.
6. **Update ComfyUI to ≥0.43.0** — 20th run carrying this; it now gates MatteDesk's LTX stage,
   Alpha-Generator, LTX-2.5 templates and openjutsu.
7. **Trial HyCanvas** on one social post (Windows zip, 35 MB) as the Canva replacement — verify `.hyc`
   export is actually portable XML before committing brand assets to it.
