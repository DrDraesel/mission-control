## 2) Top finds (all API-verified today)

### A. Lightricks/LTX-Desktop — 2,033★ · Apache-2.0 · **the 16GB-class local video suite**
Open-source desktop app (Electron) that bundles **LTX 2.5 Fast / 2.3 Fast** local generation **+
a full non-linear video editor** (text-to-video, image-to-video, audio-to-video, Retake/Extend on
2.3, LoRAs, timeline import from NLEs, text-to-image, image editing). v1.2.7 (2026-08-26);
`LTX-Desktop-Setup.exe` ~160 MB (35.6k downloads) + bundled Python env — **no ComfyUI dependency**.
- Windows + CUDA **≥16 GB VRAM = local generation** (this box's exact spec).
- Weights download from HuggingFace on first launch; newer (2.5) weights are **gated — HF sign-in
  required**. Beta ("expect breaking changes"); there is also an API-only fallback mode.
- Why it matters: closest OSS equivalent of a paid AI-video suite + editor in one app; complements
  (doesn't replace) the ComfyUI graph workflow. **Top install candidate this week.**

### B. latent-spaces/brag — 12,926★ · MIT · HyperFrames launch-video skill
"Turn the project you just created into a short, shareable launch video" — one command, powered by
**HyperFrames** (the stack already verified locally). Fetches/inspects your project, writes a
composition, renders MP4 with music + motion + share copy. Requires FFmpeg on PATH (have it);
Windows note: `git config core.symlinks true` + Dev Mode for clone. Hosted variant: letsbrag.app.

### C. tixl3d/tixl (TiXL, formerly Tooll3) — 5,122★ · MIT · realtime motion graphics
Node-based realtime animation/motion-graphics toolkit (C#/.NET, **Windows-native**), positioned
between real-time tools and AE-style motion design. `Tixl-v4.2.1.exe` (2026-08-04, ~896 MB).
Active (pushed 2026-10-01). The strongest new "After Effects lane" candidate on Windows.

### D. gitroomhq/postiz-app — 36,618★ · AGPL-3.0 · self-hosted social scheduler
The de-facto OSS Buffer/Hootsuite replacement: 30+ platforms (Instagram, TikTok, YouTube,
LinkedIn, X, Threads, Pinterest, Bluesky, Mastodon, Reddit, Discord…), visual calendar,
approval flows, **AI copilot + Canva-like design editor**, public API, n8n node, MCP; Docker
(Postgres/Redis/Temporal). No feature gating vs their cloud. Replaces Buffer/Hootsuite bills.

### E. CapSoftware/Cap → Cap — 23,008★ · AGPL-3.0 (main code; camera crates MIT)
Open-source Loom alternative: fast screen recording, local editing, share links, transcripts.
Windows + macOS desktop apps (download via cap.so — latest GH release carries **no assets**).
Useful for demo/tutorial recording in an automation pipeline; self-hostable dashboard.

### F. astrofox-io/astrofox — 1,983★ · MIT · audio→motion graphics (revived)
Turn audio into animated visuals (spectrum/wave/3D scenes). **v2.0.0 (2026-08-28)** ships
`Astrofox-windows-x64-setup.exe` (~130 MB), bundled ffmpeg for offline frame render → MP4.
Electron desktop + browser editor. Great for music-driven shorts.

### G. Wang-Alpha (WeChatCV/Wan-Alpha) — 420★ · MIT · alpha-channel video generation
CVPR 2026: generates video **with transparency** (composited overlays, glowing/soft objects).
v2.0 checkpoints + VAE open; **ComfyUI node available on HF** (htdong/Wan-Alpha_ComfyUI).
Built on Wan2.1-14B — 16GB-class with quantization/offload + base downloads. Niche but unique
for overlay/mascot compositing; revisit after ComfyUI update.

### H. Social publishing alt: inovector/mixpost — 3,762★ · MIT (Lite) · open-core
Laravel scheduler; free Lite covers FB Pages/X/Mastodon only; **Pro ($299 one-time) needed for
IG/TikTok/YouTube/LinkedIn**. Repo quiet since 2026-03-16 — prefer Postiz for active dev.
