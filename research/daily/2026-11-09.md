### `OpenTimelineIO` **0.18.1** — the timeline interchange layer the pipeline never had ✅

**2,067★ Apache-2.0** (`AcademySoftwareFoundation/OpenTimelineIO`, pushed 11-07) — the ASWF editorial-timeline API and format. It is what Nuke, Resolve, Premiere and FCP export *to* when they need to talk to each other.

**On-box evidence:**
- `uv run --with opentimelineio python …` → **1 package installed in 288 ms**, `otio 0.18.1` imported.
- Built a `Timeline → Track → Clip` with a 48-frame @ 24 fps source range → `duration().to_seconds()` = **2.0**, `otio.adapters.write_to_string(tl, "otio_json")` → **2,159 bytes** of valid OTIO JSON.
- README confirms adapter plugins for **Final Cut Pro XML, AAF and CMX 3600 EDL**. Note: after v0.16 the PyPI `OpenTimelineIO` wheel is **core-only** — the FCPXML/AAF/EDL adapters moved to the separate `OpenTimelineIO-Plugins` package.

**Pipeline role:** the missing bridge between our JSON/ffmpeg world and any NLE. `fa-render` (MeerCut) takes a JSON project, `openedit apply-edl` takes an EDL, DaVinci/Premiere round-trip OTIO — with `opentimelineio` we can read a client's `.otio`/FCPXML, retime/patch clips as data, and hand a conform back. It also gives timecode arithmetic (`RationalTime`, `TimeRange`) that does not drift like hand-rolled float seconds.

**18,636★ MIT** (`meta/astryx`, TypeScript, created 2026-01-09, pushed today — ~15.1k★ on 11-08 and 18.6k★ today, i.e. +3.5k in a day after the 11-08 open-sourcing announcement).

**Pipeline role:** not video — this is the **web/social landing-page layer**. Every reel/campaign we ship needs a matching page, deck or carousel shell; Astryx is a real design system with a CLI an agent can drive, which is exactly the thing Canva templates are used for today.
