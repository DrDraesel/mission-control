### Detail

**archify (90,194★, Apache-2.0, v3.2.0, pushed today).** The biggest unledgered repo we've hit since Recordly. Not a drawing app: the agent authors a **typed JSON IR**, Archify compiles it deterministically to HTML+SVG, then runs validators (schema, layout, route/label clearance) before deliver **atomically replaces** the last good artifact — failures return machine-readable repair codes. Ten diagram types (architecture, workflow, sequence, data-flow, lifecycle, ERD, class, tree, timeline, waterfall) plus "explainer" pages that lead with the conclusion and cite numbered sources. Exports **PNG / SVG / WebP / JPG long-image / WebM / 1200×630 share cards**. Install `npx skills add tt-a1i/archify -g`. Replaces Mermaid-as-code for anything that has to look designed; the WebM + share-card exports make it a social-asset generator too.

**hallmark (38,013★, MIT, Together AI).** Deals three themes from 48, builds the page around the visitor's task, then lints the rendered page in a real browser against AI-tells. This is the design-quality gate our HTML artifacts have been missing; pairs directly with the `html-artifact` / `claude-design` skills.

**Pixelle-Video (29,451★, Apache-2.0, renamed from AIDC-AI).** The only fully-automated "topic → finished vertical short" engine with a genuine **Windows all-in-one package** (`Pixelle-Video-v0.1.15-win64.zip`, 398.6 MB — no Python, uv or ffmpeg required). Pipelines: digital-human narration, image-to-video, atomic ComfyUI/RunningHub workflows, Edge-TTS/Index-TTS. **Caveat: last push 2026-06-14** — four months stale; treat as a benchmark/reference implementation, not a maintained dependency.

**huashu-design 3.0 (27,627★, MIT since 2026-05-14 — commercial use now free).** One prompt → web page, app prototype, **editable PPTX**, MP4 (25 fps, 60 fps interpolated) + GIF + BGM, or a print-grade infographic (PDF/PNG/SVG). 84 styles with sample sheets, six candidates → pick three directions, and an appearance "ledger" that learns your look. The strongest Canva/Keynote replacement in the lane for JasMiamiMethod decks and IG assets.

**stickman-video-director (3,157★, MIT).** Closest thing to a turnkey faceless-channel skill: it plans scenes, generates visuals + narration, adds captions and SFX, and renders to the voiceover's own timing. Honest caveat in its README: autopilot needs image/voice generation services plus a local render environment — the Skill is free, the services are not.

**kinetograph (115★, PolyForm Small Business 1.0.0, npm 0.2.0).** Existing **Remotion projects render as-is** — `remotion` and `@remotion/*` imports resolve to its own implementation — but frames are drawn by a Rust GPU compositor (wgpu, Skia, WGSL/GLSL, ThorVG Lottie, scene3d) loaded as an N-API addon, with a bundled ffmpeg for x264/x265. CLI: `render`, `still`, `strip`, `inspect`, and `npx kinetograph mcp` exposing the same commands over MCP. Two reasons to care: it drops the Chromium render path, and PolyForm-SB is free for <100 staff / <$1M revenue where Remotion's licence caps at 3 employees.

**kerf (9★, PolyForm Noncommercial).** Architecturally the exact agent-NLE shape we want: the editor *is* an API (one `Project` behind one lock, exposed twice — Tauri commands and 78 MCP tools), edits are **staged with a reviewable diff**, export is a single `filter_complex`, captions follow the cut through trim/speed/reverse, `platform_check` distinguishes hard rejections from reach limits per platform, and hardware encoders are only offered after a real test encode. **The licence blocks commercial use** and the project has 9 stars — read it as a design reference, not a dependency.
