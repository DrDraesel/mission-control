## 2) Top finds (all API-verified today)

### A. lipku/LiveTalking — 9,683★ · Apache-2.0 · real-time streaming digital human engine
The biggest find today. Text/audio → lip-synced streaming avatar with multiple backends
(**wav2lip / musetalk / ernerf / Ultralight-Digital-Human**), voice cloning, interruption
handling, WebRTC/RTMP/virtual-camera output, multi-concurrency, avatar generation from a video
upload. "已在业内获得广泛商用" (widely used commercially). Tested on Ubuntu 22.04 / CUDA 12.8;
Windows has a community package (整合包) but main path is Linux. This is the open platform for the
avatar/digital-human lane — key when a talking-presenter becomes part of the pipeline.

### B. modelscope/FunClip — 6,362★ · MIT · LLM-assisted video clipping + subtitles (FunASR)
Fully local video clipping: funasr (Paraformer-Large / SenseVoice) transcription → subtitle
generation → LLM-assisted clip selection → rendered clips, all through a local Gradio UI
(localhost:7860). v2.2.1 (2026-08) active; docs cover Windows install pitfalls; CPU-capable,
GPU optional. Chinese-optimized ASR (English via Paraformer timestamp path; Whisper "coming").
Strongest open toolchain for "long video → captioned clips" that also does raw subtitles.

### C. Anil-matcha/AI-Youtube-Shorts-Generator — 5,234★ · MIT · OpusClip alternative with FULL local mode
Drop in a long YouTube video → ranked 9:16 shorts. Two modes: `--mode local` runs **entirely
offline** (yt-dlp + faster-whisper CPU/CUDA + local cropping); `--mode api` uses MuAPI.
CLI + Python library (`generate_shorts(...)`). Missed by earlier sweeps; now in the ledger.
Pairs with FunClip/B for the clip-factory lane.

### D. Clips Kitty (ColinGPT9/clips-studio) — 85★ · AGPL-3.0 · local Opus Clip alternative for Windows
Paste a YouTube/Twitch/Kick link or local file → best moments found, 9:16 crop with speaker
tracking, word-synced captions, titles/hashtags written; **pushed today**; Microsoft Store
presence. Requirements: Windows 10/11, min RTX 2060 (6GB), 16GB RAM required; CUDA + NVENC/AMF/QSV
with CPU fallback. Young stars but the most complete self-hosted clipper UI for this box.

### E. bytedance/LatentSync 1.6 — 6,106★ · Apache-2.0 · SOTA lip-sync (+ Windows ComfyUI wrapper)
ByteDance lip-sync diffusion (512×512 v1.6; fixes blurriness). **Min VRAM: 8GB (1.5 documented)** —
comfortably within the 16GB ceiling. For ComfyUI: **ShmuelRonen/ComfyUI-LatentSyncWrapper — 962★**
(unoffical 1.6 port, Windows + WSL2) — queue for right after the pending ComfyUI update.
Context: Rudrabha/Wav2Lip (13,229★) is now in the ledger too, but has **no license file** — research
model only; LatentSync is the usable open path.

### F. Capite — 9★ · MIT · self-hosted animated-caption studio (motion typography)
Word-timed animated captions with **27 motion-typography presets** (Hormozi/MrBeast/karaoke…),
interactive word-level transcript editor, fast re-render without re-transcribing, burns via
pysubs2 → `.ass` → FFmpeg libass; exports MP4/SRT/VTT/TXT/ASS; 100+ languages. Next.js 16 +
faster-whisper + Docker or plain Python. Direct fit for the "typography animation on captions"
gap; low stars (new) — trial.

### G. met4citizen/TalkingHead — 1,585★ · MIT · real-time 3D talking head in the browser
JS class for real-time lip-sync on full-body 3D avatars (GLB/VRM), with animation, physics
(dynamic bones), and TTS integration (incl. HeadTTS/Kokoro). Runs entirely in-browser — the
web/social-asset lane for avatar presenters without a GPU.

### H. Wunjo Make (wladradchenko) — 1,173★ · GPL-3.0 · local video editor + AI toolkit
Full video editor built on the Kdenlive codebase with face swap, lip sync, object/text/background
removal, restyling, voice clone, video generation, plus **MCP server** + Python plugin system.
Free community editions (v2.0.8 CE) with Windows builds. All-local suite for creator post.

### I. PunithVT/ai-avatar-system — 517★ · MIT · real-time AI avatar platform
Photo + cloned voice → real-time talking head (MuseTalk / Chatterbox / Whisper stack);
FastAPI + Next.js; runs 100% locally (or AWS g5). The deployable multi-user variant of the
avatar lane; lighter than LiveTalking for single-machine use.

### J. SuperCMO-skills — 66★ · Apache-2.0 · agent skills for marketing video production
Skills that let any AI agent (README explicitly lists Hermes) build end-to-end marketing
campaigns: UGC videos, ad videos, product photography. Local minimal MCP server via `uvx`;
bring-your-own model keys. Direct match for social-media-asset automation.
