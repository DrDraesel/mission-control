## 1. Verified on this machine — takumi renders HTML to PNG in **4–5 ms** (no browser, no JSX)

**`kane50613/takumi` — 3,189★, Apache-2.0, pushed today.** 2.20.0 on npm as `takumi-js` (+ `takumi-pdf`, `takumi-paint`), MIT OR Apache-2.0, prebuilt Windows x64 native binding — `npm i takumi-js` pulled **5 packages in 4 s, no compile step**.

**On-box evidence:**
- **HTML string input works** — `render("<div style='…'>…</div>", {width, height, fonts})`. The type is `RenderInput = ReactNode | ReactElementLike | Node | string`, so no JSX toolchain, no React, no `tsx` is needed for our use. (The README's JSX examples need a JSX transform; `tsx` fails on top-level await in CJS and then on `React is not defined` — I went with the string form and it is the better agent path anyway.)
- **1080×1080 IG card**: first render in a cold process **221 ms** (includes Google-font fetch); then four 1080×1350 variants at **5, 4, 4, 4 ms** each, 8.7–10.1 KB PNGs. Layout verified by eye: three rows, no clipping, Inter rendered correctly.
- **PNG output is `pal8`** (palettized, ~9.5 KB at 1080×1350). Fine for flat brand cards; it *will* band on gradients/photo backgrounds.
- **`format: "raw"` is the ffmpeg hook**: exactly `1080*1080*4 = 4,665,600` bytes out; `ffmpeg -f rawvideo -pix_fmt rgba -s 1080x1080 -i frame.raw` → PNG `rgba` 86 KB, gradient intact. That is HTML → raw RGBA → `ffmpeg` with **no Chromium anywhere**.
- **`renderAnimation`** → 3-scene animated WebP: `webp_anim`, 1080×1080, **3 frames** (one per scene, 1 s each — scenes are static nodes; CSS `@keyframes` are what get sampled at `fps`), **7,858 bytes in 248 ms**. Each frame extracted with ffmpeg and inspected: "STEP 2 / 3", "Train", teal, centered.

**Why it matters:** 4–5 ms warm at 1080-wide is the same order as `raea` (6.2 ms at 1080p) but with a completely different surface — takumi is **CSS/HTML layout**, i.e. the Satori/next-og replacement for cards, carousels, thumbnails, PDFs and quote slides. OpenEdit does the same job at **105 ms/frame through headless Chrome**. Puppeteer is now optional for every static social asset we make.

## 2. Verified on this machine — `@google/design.md` 0.4.0 is a real design gate

**`google-labs-code/design.md` — 28,819★, Apache-2.0, TypeScript, created 2026-04-10, pushed 11-06.** A 28.8k★ repo that no sweep has named in three weeks, because the obvious probe (`design system`) is drowned by *system design* interview repos — see §6.

- `npx @google/design.md` hung on this box (registry fetch under npm 11); `npm i @google/design.md` worked and exposes two bins, **`design.md`** and **`designmd`** (the README itself warns the `.md` suffix confuses Windows command resolution — use `designmd`).
- `design.md lint --format json DESIGN.md` → `{"findings":[{"severity":"info","message":"Design system defines 4 colors, 3 typography scales, 2 rounding levels, 2 spacing tokens.","rule":"token-summary"}],"summary":{"errors":0,"warnings":0,"infos":1}}`, exit 0.
- `design.md export --format css-vars DESIGN.md` → `:root{--color-primary:#1a1c1e; …}` (also `css-tailwind`, `json-tailwind`, `dtcg` W3C tokens).
- **Honest limit:** a deliberately near-white-on-white palette linted **clean** — contrast findings need an explicitly declared pair, so the gate reports what the spec declares, it doesn't invent surfaces. Treat it as a schema/token linter (with WCAG available), not an accessibility oracle.

## 5. Known-good, momentum update — **ReelMimic** is a faceless-content studio now

**`edenfunf/reelmimic` — 1,909★, MIT, pushed 11-08** (ledgered 11-01 at 314★; its stars were zeroed on 10-20 when the repo went briefly private and have since recovered 6×).

Reference video (file, phone clip or YouTube link) → breakdown (shot lengths, BPM, transitions, framing, camera moves) → plan you approve → **up to 6 Claude Code/Codex agents** build and cross-review shots. Seven engines: vector/motion graphics (**HyperFrames**), hand-painted (**painted-animation**), crayon, pixel art, paper cut-out, whiteboard doodle, anime cel. Local web UI on **:4318**, `install.bat` / `start.bat`, **tested mostly on Windows**, styles are one Markdown file each, optional `npm run post-video` publishing (dry-run unless `--send`).

Cost is the catch: every frame is built by your own Claude Code or Codex plan, and a 30–60 s video takes **1–3.5 h**. But it is the only tool in the ledger that closes the loop from *reference reel → original 2D animation* with no image/video model and no GPU.

## 10. Integration plan

1. **Make takumi the static-asset renderer.** One `card.mjs` that takes a JSON payload (title, kicker, palette, size) and writes PNG or raw RGBA; feed the raw path straight into ffmpeg for video cards. Keep OpenEdit only for pages that need real HTML *layout* at video length.
2. **Adopt `DESIGN.md` as the brand source of truth** — one file per client (start with JasMiamiMethod), `designmd lint --format json` as a pre-render gate, `export --format css-vars` into the HTML templates takumi rasterizes. Same tokens feed astryx components for web.
3. **Test musializer's export path** (Windows binary + ffmpeg child process) before building any beat-reactive visual by hand.
4. **Queue ReelMimic** as the reference-cloning faceless studio; run one 20 s reference end-to-end and record wall-clock and plan usage.
5. **ComfyUI update stays action #1** (20 versions, 28th run). One update unblocks Sonder Editor, Panorama Stickers, WeVisOne-VL, Kandinsky 6 and the LTX templates at once.
6. **Rotate tomorrow:** `image-to-3d`, `depth estimation`, `screenshot-to-code`; keep `code-rendered-film`, `fresh-ltx`, `matting`, `blender-addons`; retire `image-upscaling`, `music-visualizer`, `design-system` (all three done).
