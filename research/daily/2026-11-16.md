## 1. Verified on this machine — `Drift 0.9.2` is a headless NLE with a full MCP API (the find of the week)

`CutWire-Studios/Drift` — **2,434★, GPL-3.0**, Windows/macOS/Linux/Android, Qt 6 + FFmpeg, v0.9.2 published **11-14**. It has been in the ledger since **2026-09-25** and every run since reported it **OLD** — the "ledgered ≠ evaluated" lesson, again, and this time it was hiding the biggest automation surface in the ledger.

**Why it matters:** this is the first **headless NLE with a real agent API** in the ledger. `docs/MCP.md` documents three transports (`--headless` stdio, `--headless --mcp-port` HTTP, `drift --mcp-stdio` attach-to-open-editor), multi-instance registry, and **25 toolboxes**: `timeline, canvas, text, shapes, motion (Lottie/SVG), model3d (glTF), subtitles (Whisper generate + SRT/VTT import/export), effects, keyframes, speed, segmentation (SAM-style cutout), ai (denoise, face detect, auto-reframe, depth estimation), audio (waveforms, silence, loudness, ducking, beat detection, beat-synced cuts), scene (shot detection), multicam, transcript (word-level cuts, speaker labels), voice (TTS/SFX), market, project`. `activity()` profiles motion/loudness to tell you *where* to look, `frames()` returns one labelled contact sheet, `capture()` returns a still — i.e. the agent can **see what it rendered without leaving the protocol**.

**Caveats:** GPL-3.0 (internal/client work fine; shipping a fork = GPL). Binds `127.0.0.1` only, token rotates per session, `apply` is **not atomic**. Harmless noise on start: `qt.qpa.screen … Unable to open monitor interface` and `no audio output devices`. The GUI itself remains the primary product — no `--version`, no batch CLI.

## 7. Integration plan

1. **Adopt Drift as the NLE renderer** (`~/.local/opt/drift-0.9.2/Drift/drift.exe --headless --mcp-port 4731`, kill after use). It replaces fa-render for anything that needs text/subtitles/effects/timeline, and it is the only renderer that can *show* the agent its own output (`capture`/`frames`/`activity`). Write a thin Hermes MCP client (8 tools) and a `drift_render(project_ops, out.mp4)` helper.
