## 2. Top finds today

### ⭐ 1. `oso95/scroll-world` — 10,690★ MIT — the 3D-web lane's 10.7k★ ledger gap
An agent skill (Claude Code plugin, or `npx skills add oso95/scroll-world`) that builds a **scroll-scrubbed "fly through the world" landing page** for any brand: as you scroll, a camera flies from outside each scene into its interior and on to the next with **no cuts** — one continuous connected flight through a generated world (the Emons-logistics-site effect).
- Ships the thing that actually matters: a **portable vanilla-JS scrub engine** (frame-locked camera video → scroll position), framework-agnostic — drops into plain HTML, Next.js, Vue or a Python-served page.
- Assets are generated (isometric dioramas via GPT Image 2, camera flights via Seedance/Kling on Higgsfield or Monid) — **paid keys for the art**, but the engine, prompt templates and pipeline are free and re-runnable with your own art.
- Caveat: created 07-06, **dormant since 07-29**. Take the engine and the method, not the maintenance.

### 2. `rtmandreyev/construct` — 50★ Apache-2.0 — describe a thing, get a 3D model **and** a hologram page
Scene is **data, not code**: an agent (Claude Code, **Hermes**, any MCP client, any OpenAI-compatible endpoint) writes a text scene — metres, parts, assembly order, joints — and a deterministic engine renders it. Nothing to install (stdlib Python + a browser), no API keys, works offline.
- Output: one `construct.html` (orbit, replay the assembly, read labels) **plus** glTF `.glb` / `.obj` with **named parts and working joints**, a Blender 4.2+ add-on, Khronos-validator-clean, `--merge` to cut draw calls (300 → 27 on their FJ62 example).
- 24 subcommands incl. `export`, `video`, `review`, `check`, `critique`, `terrain`, `globe`.
- **Why it matters here:** this is the cheapest route to *explainable* 3D — a force plate, a treadmill rig, an EEG montage — as patient-education pages and marketing assets, with no Blender session and no install. It also self-audits ("something floating, a claim stronger than its evidence, a part too thin").

### 3. `blendi-remade/dioramas` — 841★ MIT — 20 finished cinematic 3D landing pages, free
A three.js engine tuned to make generated models look expensive (N8AO ambient occlusion, mip-chain bloom, AgX tone mapping, grain + vignette, **raymarched volumetric spotlights**, planar reflections with roughness blur, GPU-baked procedural textures, Lenis + GSAP scroll choreography) with **20 complete example sites** — submersible with steerable floodlights, museum with a lantern, watch-movement assembly, damascus forging.
- Asset pipeline is prompt → Nano Banana 2 plate → Meshy 7.1 image-to-3D → `optimize.mjs` (meshopt + WebP; 25 MB → 3–8 MB). **~$1.20 per textured model; the whole 20-scene set cost ~$90 once** — after that the site is yours.
- No account, no CLI, no paid tier. Hand a brief + `docs/ENGINE.md` to an agent and it builds your own world.

### 4. `Bingeljell/image-to-3dlab` ("AssetFurnace") — 1,035★ Apache-2.0 — image → rigged, animated 3D character, locally
Prompt or picture → textured, **rigged, animated** game character with auto-rig and 21 moves, chaining Pixal3D, TRELLIS.2, Hunyuan3D and SF3D. Runs locally on **NVIDIA or Apple Silicon** (i.e. this box). Pushed 10-30, actively developed. This is the missing link between "a concept image" and "an asset a 3D scene can use" for scroll-world/dioramas/construct.

### 5. `Pika-Labs/Pika-H3-Flex` — 252★, created 10-29 — **the week's biggest video release, and it is legally unusable from the US**
Pika's post-train of MiniMax H3: **6 sampling steps**, up to 12 references (9 images / 3 videos / 3 audio), native **480p/768p video with synchronized stereo audio**, 5–15 s @ 24 fps, 11 aspect ratios; 1080p/2K/4K + separated audio stems only via the paid Pika API ($0.01–0.02/s intro).
- **Blocker, verified by reading the LICENSE file:** it is the **MiniMax H3 Community License**, whose §I.5 defines *Excluded Territories* as **the European Union, the United Kingdom, the Republic of Korea and the United States of America**. We are in the US → **do not adopt, do not ship**. (Same trap as H3 itself; the README does not say this, the LICENSE does.)
- The whole "Open Source Higgsfield" wave inherits it wherever H3 is the video model.

### 6. `EverettFish/holo-card-studio` — 2,026★ MIT (raw LICENSE verified; API says NOASSERTION) — holographic 3D trading-card skill *(ledgered 09-25 at 1,857★ — re-surfaced, +169★)*
One sentence → four generated layers → a Blender scene with parallax/laser/sparkle → an interactive Three.js page **plus the editable `.blend`**. The nicest "collectible social asset" generator found so far (card art, numbered editions, tilt-to-shine). Chinese-first docs; needs an agent with image generation + Blender.

### 7. `sirioberati/showhow` — 38★ MIT, created 10-29 — explainer reels whose render *self-checks*
Script → voiced in one take with real character timings → every motion `cue("word")`-keyed to the spoken word → 1080×1920 @ 60 fps → **five checks print PASS/FAIL** (too fast to follow, a cut, a freeze, a bad scene change, wrong loudness) and a FAIL goes back to its scene. Honest caveat: needs an ElevenLabs key + whisper.cpp. The **check suite** is the reusable part — it is the same discipline as the `impeccable detect` gate, applied to motion.

### 8. The "Open Source Higgsfield" contest wave — ComfyUI studios on open weights
Comfy ran a two-week challenge to rebuild Higgsfield's apps. The entries are real, MIT, and mostly one folder per app:
- **`neuregex/freefield` 412★ MIT** — every app is `app.json` + an API-format workflow; models all open weights with sizes + licences declared; web UI, runner, downloads and per-app VRAM map all derived from the manifests. Cleanest architecture in the set.
