## 1. Verified on this machine — the faceless pipeline, end to end

`Chamanrajragu/purffle-shorts` has been **in the ledger since 2026-09-26** (50★ then, reported OLD on every run since) and had never been run. That is the "ledgered is not evaluated" trap again: it is now 94★, and it is the first keyless faceless-shorts pipeline measured on this box.

| Step | Measured here |
|---|---|
| install | `uvx --from git+…/purffle-shorts` → 53 packages, **1.05 s** (uvx cache) |
| CLI surface | `run / make / clip / plan / ideas / stats / mcp / upload / auth / doctor / providers / history / voices / studio / demo` — exit 0 |
| **`purffle-shorts demo`** (offline script, free edge-tts voice, no keys) | exit 0 |
| voice | `edge/en-US-AndrewMultilingualNeural`, 25.0 s, **77 words with native word timings** |
| captions | **135 caption states** rendered with per-word colour highlight |
| audio | 6 synthesised SFX, soundtrack ducked and normalised to **−14 LUFS** (two-pass) |
| render | **1080×1920 @ 30 fps, h264 + aac, 25.608 s, 4,260,495 B — in 11 s wall** (README claims 30–40 s on an Intel Mac) |
| artifacts | `short.mp4` + `cover.jpg` (67.8 KB) + `captions.srt` (1.5 KB) + `metadata.json` (title/description/tags/category) + `script.json` |
| frame at t=12 s | inspected — bold all-caps caption, **active word in yellow** between white and green neighbours, top progress bar + small brand header, clean layout on a generated gradient |

Honest limits: the demo had no footage (Pexels/Pixabay keys absent) so every scene fell back to a generated gradient background — the *structure* is production-grade, the *art* needs stock footage, your own gameplay/plate, or AI stills. Python 3.10–3.13, ffmpeg only (no MoviePy, no ImageMagick, no GPU). Ships a **local Studio on :8765**, a documented **JSON REST API** (`POST /api/make` → job id → `GET /api/jobs/1`) and an **MCP server** — i.e. it is drivable by cron, n8n, or an agent, which is the part that matters for automation. Caveat: the README cross-promotes the author's paid tools; the code itself is MIT.
