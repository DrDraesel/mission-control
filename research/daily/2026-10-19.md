## 2. Top finds (new today)

### 2.1 `open-pencil/open-pencil` — 9,126★ · MIT · v0.16.0 ⭐ TOP PICK
AI-native design editor, positioned as the open-source Figma alternative — and the closest thing yet to a **scriptable Canva**. Tauri v2 + Skia + Vue + WebGPU, ~15 MB desktop app, reads `.fig` files natively, runs as PWA.
- **Automation surface (the reason to care):** headless CLI `@open-pencil/cli` — `export design.fig` → PNG/JPG at 2×, `-f tailwind-jsx`, `-f storybook`, `convert design.pen design.fig`, `import card.html --css card.css`, and `eval` against the **Figma Plugin API**; **MCP server** `@open-pencil/mcp` exposes **100+ tools** for agents (shapes, fills, auto-layout, components, variables, booleans, token analysis, asset export).
- **Windows:** 10+; `OpenPencil_0.16.0_x64-setup.exe` 13.3 MB (995 downloads), arm64 MSI also published.
- **Why it matters here:** the IG/social-asset step currently ends in Canva by hand. With OpenPencil the template is a `.fig`, the copy is data, and `openpencil export` produces the PNG set — no seat, no upload, no browser automation.

### 2.2 `renezander030/capcut-cli` — 923★ · MIT · npm 0.30.0 ⭐ TOP PICK
Independent CLI for **CapCut / JianYing project files**: reads and writes the local draft store (`draft_content.json`, `draft_info.json`) directly — *JSON in, JSON out, no MCP server, no HTTP daemon, no upload*. Commands cover `quickstart`, `add-video`, `caption`, `import-srt`, `cut-to-short`, `translate`, `render`, plus `serve` for a JSONL job queue (n8n/Make) and a read-only WASM sandbox for agents.
- **Verified:** `doctor` → `{"ok":true,"platform":"win32 10.0.26300"}`; Node 24 fine; zero native modules.
- **Two gotchas:** (a) it produces **editable drafts, it does not replace the editor** — you still need CapCut/JianYing installed to open and render (not installed on this box today); (b) `caption` needs Whisper on PATH (none here) unless you feed `--words aligner.json` or `import-srt`.
- **Why it matters:** a deterministic, agent-drivable path into a real multi-track NLE without Premiere. For JasMiamiMethod this is the "generate the rough cut + karaoke captions, human approves in CapCut" workflow, fully scripted.

### 2.3 `tomastimelock/text-fx` — 0★ · MIT · PyPI `text-fx-engine` 0.1.2 ⭐ VERIFIED IN USE
**120 named text-overlay effects through 25 base engines**, purpose-built for Python video pipelines: 18 basic, **25 kinetic-typography**, 22 mask-reveal, 20 glitch/digital, 20 distort/warp, 15 light/neon. Single `TextEffectConfig` Pydantic model; renders one overlay at a time to transparent WebM **or composites straight onto a base video** via ffmpeg.
- **Smoke test here:** 125 effects enumerated; `render_overlay('JASMIAMI METHOD','kinetic_pop',1080×1920,1.5s)` produced a valid VP9 file. Needs `ffmpeg>=6` (we have 9.0.2). Pillow default engine; OpenCV auto-selected for displacement effects; optional Chromium pass for neon effects.
- **Why it matters:** this is the missing "caption/title vocabulary" layer for `moviepy`/raw-ffmpeg pipelines — the consumer-editor look, addressable by **effect name**, which is exactly what an LLM can pick from a JSON schema.

### 2.4 `dmtrKovalenko/fframes` — 2,867★ · MIT · v1.2.0
"Video vibe coding that is actually fast": videos authored in **Rust + SVG**, rendered on the GPU via Skia (**Vulkan on Windows**, ~10× the CPU backend). Ships an agent skill (`npx skills add https://fframes.studio`) that takes an agent from empty folder to `.mp4`, plus `inspect`/`preview` commands that turn a video into things an agent can read (PNGs, text, numbers) for self-QC. 128-second launch film rendered in 36 s.
- **Cost:** Rust toolchain + LLVM + prebuilt FFmpeg 9.0 shared on Windows; first build up to ~20 min.
- **Position:** third contender (with framefields and HyperFrames) for the render step — the only one that is Rust-native, GPU, and has a self-inspection loop.

### 2.5 `omni-media/omniclip` — 1,468★ · MIT
Browser NLE running entirely on WebCodecs: trimming, splitting, effects, local-only storage, no accounts. Embeddable components. 2.0 rewrite in progress; no release binaries. Good reference for a browser editor, not a pipeline component.

### 2.6 `bridge-mind/bridgeclip` — 379★ · MIT
Desktop app that turns long podcasts/streams/interviews into **captioned short clips**: moment finding + refine + export. Rendering is local; AI runs on **your own OpenRouter key**. Windows installer verified. Direct OpusClip substitute for the long→shorts lane.

### 2.7 `Sportinger/MasterSelects` — 454★ · AGPL-3.0
Browser NLE with a genuine pro feature list: multitrack + nested comps, **Premiere Pro sequence import**, node-graph effects, audio stem separation + score editor, motion/captions/tracking, 3D with Gaussian splats, in-app agent, WebGPU + WebCodecs local render. Optional native helper MSI for Windows. AGPL is fine for internal use; a hosted product would trigger it.

### 2.8 `BintzGavin/helios` — 121★ · **ELv2 (not OSI)**
Programmatic video where **plain CSS animations just work** — it virtualises the browser clock through CDP (`Emulation.setVirtualTimePolicy`) instead of screenshotting frame by frame, so animations are frame-exact and fast. `npx @helios-project/cli render page.html -o output.mp4`. Ships `helios.mcpb` for Claude/ChatGPT/Codex. **Licence flag:** Elastic License 2.0 — usable, but not open source; no managed-service resale.

### 2.9 `ybouane/VideoFlow` — 166★ · Apache-2.0
Programmatic video as a **portable JSON IR**: fluent TypeScript API → JSON → three renderers (server MP4 via headless Chromium, browser MP4 via WebCodecs + MediaBunny, live DOM playback with scrubbing). Resolution-independent `em` units. Same architectural family as framefields, but JSON-first — easier to diff and to generate from a planner.

### 2.10 `TangSY/aedifex` — 90★ · MIT
WebGPU architectural editor (walls with auto-mitering, doors/windows, auto-detected zones, multi-level, slabs/ceilings/roofs, lean-to + drainage) with a natural-language AI design assistant. The active challenger to the dormant Pascal Editor in the 3D-web lane.

### 2.11 `Gitruck/cli` — 793★ · MIT · npm `@gitruck/cli` 1.3.8
Agent-first Chinese video CLI: raw talking-head → editable project with cut/dubbing/commentary/motion cards/subtitles; Windows/macOS/Linux CLI, **Windows desktop client**. **Cloud dependency:** its AI capabilities require an API key from `cloud.ai-mcn.tv` with credits. Useful as a benchmark of the lane, not as a free pipeline.

## 4. Automation / editors / social assets

- **The design step is now automatable end-to-end.** OpenPencil's CLI + MCP closes the last manual gap in the social-asset loop: `.fig` template in the repo → data-driven text → `openpencil export` → 1080×1350 PNGs. This replaces Canva, not just approximates it.
- **Typography is solved at the Python layer** with `text-fx-engine` (verified). Pair it with ffmpeg `drawtext` only for simple lower-thirds; use `text-fx` when the look has to be "consumer editor" rather than "developer".

- **Meta-resource:** `zhuyansen/awesome-claude-video-skills` (727★) indexes **309 agent video repos with security grading** and a same-task bake-off — the fastest way to survey this lane each week.
