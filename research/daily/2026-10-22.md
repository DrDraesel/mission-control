## 2. Top finds

### 2.1 `yikart/AiToEarn` — 26,736★ · MIT — the ledger gap of the week
A content-marketing agent for "one-person companies": four modules — **Create** (AI video/image drafts, Seedance 2.0 / HappyHorse 1.0 / Nano Banana Pro, script translation, multi-language subtitles, batch matrix creation), **Publish** (14 platforms: Douyin, Rednote, Kuaishou, Bilibili, WeChat Channels, TikTok, YouTube, Facebook, Instagram, Threads, X, Pinterest, LinkedIn), **Engage** (browser extension auto-likes/bookmarks/follows + LLM comment replies mining buying intent), **Earn** (task settlement).
- MIT, TypeScript, created 2025-02-24, **pushed 10-20**. Distribution: hosted site, OpenClaw, **MCP server** for Claude/Cursor, **Docker self-host**, or source. Electron desktop app.
- **Caveats:** latest release is **v2.5.0 (06-24) with zero binary assets** — desktop builds come from the site, not GitHub. Docs are Chinese-first (English README exists). MCP/Claude use requires an API key (their relay or your own). 14-platform publishing means platform authorizations and ToS exposure.
- **Why it matters:** this is the closest thing to a free Hootsuite/Later + Canva-scheduler + engagement bot in one repo, and it is the social-publishing lane we have only been tracking at 3–8k★.

### 2.2 `presenton/presenton` — 11,267★ · Apache-2.0 — decks, not slideshows
Open-source **AI presentation generator + API** (Gamma / Decktopus / Canva alternative). Prompt or document → **fully editable PPTX** or PDF, with template import from your own PPTX, drag-edit UI, and a **self-hostable API**.
- **Windows:** README states Docker / Windows / macOS / Linux; Electron desktop app downloadable at `presenton.ai/download` (the GitHub release `electron-v0.9.11-beta` only ships `.AppImage`, `.deb`, `.dmg` — no Win asset in the repo, so use the site build). Docker: `docker run -p 5001:80 -v "./app_data:/app_data" ghcr.io/presenton/presenton:latest` (PowerShell variant documented).
- **Pipeline position:** turns a research report or brief into a client-facing deck without Canva; API is scriptable for batch generation. Not a carousel maker — for IG 1080×1350 PNGs the HTML/Puppeteer route (open-pencil, diagram-design) still wins.

### 2.3 `shaongitbd/doory` — 1,736★ in 12 days — a Canva clone that actually exports MP4
Full browser design editor: posters, social posts, stories, slides, resumes, thumbnails; **10 starter templates** in open-licensed fonts; export **PNG/JPG/SVG/PDF/MP4/GIF**; real-time co-editing (Yjs) and comments; background removal in-browser; no account.
- Stack: **React 19 + Fabric.js + Yjs + Zustand** client, **Django 5 + DRF + Channels + PostgreSQL** server, Docker Compose (nginx, optional Redis/S3). Created 10-10, pushed 10-20, 131 forks.
- **License: "Attribution Assurance License"** (PGP-signed file → API reports NOASSERTION). It is an OSI-approved attribution license: fine for own and client work, but you must preserve attribution and license notices — don't strip it. Not a copyleft trap.

### 2.4 `soumatheusgomes/editonny` — 330★ · MIT — local editing by conversation (3 days old)
Local video editing through chat, Python. Created 10-19, pushed 10-21, no releases yet (source only). Early, but it is the exact shape of the agent-NLE lane with a permissive license and no Electron.

### 2.5 `SupercmoHQ/superCMO-skills` — 161★ · Apache-2.0 — the marketing-skills kit
**20+ skills + a local MCP server** (`uvx supercmo-skills`, stdlib-only) that turn Claude Code/Codex/Cursor/Hermes into an ad agency: `generating-ugc-videos`, `generating-ad-videos`, `cloning-video-ads`, `generating-product-photos`, `researching-competitor-ads`, `adapting-formats`, `writing-ad-copy`, `planning-campaigns`, `analyzing-brand`… Every generation supports **`dry_run`** (exact request, no API call).
- Install: `npx --yes @supercmo/skills@0.1.27 --all` (needs `uv`). **BYOK** keys live in `~/.supercmo/.env` and requests go straight to the vendor; their managed key routes through their proxy (billed).
- **Verified locally:** npm package exists at 0.1.27 (Apache-2.0, 19 versions), installer executes — but it rejects unknown flags, so don't smoke-test it with `--help`.
- **Why it matters:** this is the marketing-production layer for JasMiamiMethod — competitor-ad research + format adaptation are things we currently hand-build.

### 2.6 `riecodes/free247editor` — 119★ · MIT — agent-skill editor, **Windows 11 tested**
"Drop in a raw video, say *edit this*" inside Claude Code / Codex / Cursor / Copilot. Returns a cut, captioned edit with motion graphics, zoom-ins and sound; notes in plain words. **README states it is tested on Windows 11** with Claude Code (setup, test render, transcription, cutting). Needs Node 22+, Git, FFmpeg, Chrome; `faster-whisper` for transcripts.
