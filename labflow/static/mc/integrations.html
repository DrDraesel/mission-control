When a source is unreachable

  • Bertec — open Bertec Jump and finish a protocol; sessions are read from bertec-jump/data/protocols/*/session.json.
  • RunTrack — start RunTrack and complete a session; runtrack/data/runtrack.db must exist and be readable.
  • NeuroSync — record a session. An empty recordings/ folder is a valid empty state, not a failure.
  • InBody — no device API is contracted. Enter values by hand and verify them against the device printout.
  • Intake — comes from LabFlow’s patient store; create or edit the patient in LabFlow.
