    How this record is assembled

    • Adapters are read-only. Mission Control never writes into Bertec, RunTrack, NeuroSync or InBody.
    • Quality is carried from the source, never upgraded here — an uncalibrated or simulated session stays marked as such.
    • Every value keeps its source session and file/endpoint; hover a value to see it.
    • Sessions without an explicit patient link stay unlinked; they are never merged silently.
    • The export is a self-contained HTML file for printing — it is a lab record, not a signed clinical document.
